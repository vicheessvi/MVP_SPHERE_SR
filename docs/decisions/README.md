# Architecture Decision Records

ADR используются для фиксации важных решений.

## Формат ADR

- Статус
- Контекст
- Решение
- Последствия
- Рассмотренные альтернативы

## Когда создавать ADR

- выбор технологического стека;
- выбор базы данных;
- архитектурный подход;
- подход к деплою;
- авторизация/аутентификация;
- подключение крупной библиотеки или фреймворка;
- изменение проектного workflow.
