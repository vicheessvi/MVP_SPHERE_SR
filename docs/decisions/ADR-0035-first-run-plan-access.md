# ADR-0035: Первый локальный вход в план опроса

Статус: реализовано локально, 2026-10-30.

Администратор задаёт собственные логин и пароль при первом запуске на каждом ПК. Python runtime атомарно создаёт в профиле текущего пользователя Windows вне Git файл `admin-access.json` с солью, версией и scrypt-проверочным значением. Открытый пароль не записывается. При следующих запусках право доступа выдаётся только текущей одноразовой loopback-сессии после успешной серверной проверки.

До входа все `/api/polling/*` отклоняются, включая передачу учётных данных оборудования, создание, чтение, отмену и подтверждение результата задания. Origin/CSRF и одноразовый launch token сохраняются. После пяти неуспешных попыток вход временно ограничен. Выход очищает временные пары оборудования и закрывает право доступа; при активном задании выход отклоняется, чтобы не нарушить подтверждение записи результата. `file://index.html` остаётся ручным режимом без сетевого опроса.

Файл проверочного значения наследует права каталога профиля Windows. Он не защищает от владельца этого профиля или администратора ОС, способного менять исходный код и файлы. Утерянный пароль не получает автоматический fallback; сброс требует отдельного явного локального действия. Пароли устройств в проверочном файле запрещены.

Решение основано на Constitution 4.0.0. Клиентское скрытие формы — только интерфейс; реальная граница находится в Python runtime. Перед эксплуатацией необходима проверка первого запуска на другом ПК и независимая security review.
