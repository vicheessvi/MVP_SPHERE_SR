# ADR-0028 — Случайный интервал между устройствами

## Цель и область

План автоматического опроса принимает две границы интервала в целых секундах: «От» и «До». После подтверждения записи результата предыдущего устройства и перед следующим поддерживаемым устройством Python-runtime независимо выбирает значение из включительного диапазона. Перед первым устройством и после последнего дополнительной паузы нет. Порядок устройств, ACK записи, фильтры, адаптеры и безопасность учётных данных не меняются.

## Решение

- В плане schema v3 используются `intervalMinSeconds` и `intervalMaxSeconds`; обе границы обязательны вместе, целые, неотрицательные, `min <= max`.
- Исполнитель использует `secrets.randbelow(max - min + 1) + min`: обе границы достижимы и выбор повторяется для каждого перехода.
- Ранее созданные планы с `intervalSeconds` по-прежнему принимаются как диапазон с одинаковыми границами. Новые планы не сохраняют фиксированное поле.
- Значение `0` допустимо и означает переход без паузы. Интервал не помещается в JSON результата и не содержит секретов.

## Проверка и риск

Границы проверяются при построении плана, на loopback API и в исполнителе. Регрессия охватывает включительность границ, независимый выбор между тремя устройствами, неверный диапазон и старый фиксированный план. Реальный сетевой опрос не требуется для проверки механизма интервала; длительность фактического ожидания может отличаться от выбранного числа секунд на время планирования ОС.
