# ADR-0007: Непостоянный прямой запуск index.html

## Статус

Принято, 2026-08-10. Дополняет ADR-0005 и ADR-0006, не отменяя защищённый runtime.

## Контекст

Пользователь явно потребовал открывать проект двойным щелчком по корневому `index.html`. Страница `file://` не может обращаться к Windows DPAPI, локальному Node.js API или HttpOnly/CSRF session. Сохранение SR, внутренних IP, результатов опроса и аналитики в `localStorage` противоречит Constitution 2.0.0; хранение credentials в browser storage прямо запрещено.

## Решение

- Разрешить подтверждённый `file://` запуск через статический `runtime-config.js`.
- На каждую загрузку страницы создавать новый синхронный in-memory storage adapter.
- Не читать и не записывать рабочее состояние в `localStorage`, IndexedDB или файлы браузера.
- Не показывать credential file input в файловом режиме и отклонять обработку до `FileReader` как дополнительную защиту.
- Не выполнять storage/credential API requests из файлового режима.
- Сохранить server-issued secure marker, CSRF, AES-256-GCM, DPAPI CurrentUser и vault при запуске через `start.ps1`.
- HTTP/HTTPS без подтверждённого secure marker оставлять заблокированным без browser fallback.
- Удалить три повторяющихся глобальных защитных уведомления; свойства хранения показывать только контекстно и в соответствии с активным режимом.

## Последствия

- Проект открывается без Node.js и установки; импорт и аналитика работают до reload/close.
- Файловый режим не является постоянным хранилищем. Пользователь повторно импортирует исходные данные после перезагрузки.
- Учётные данные и автоматический сетевой polling требуют `start.ps1`.
- Защищённый режим не ослаблен и остаётся единственным режимом постоянной рабочей базы.

## Альтернативы

- `localStorage`/IndexedDB отклонены как постоянное незашифрованное browser storage.
- Ключ Web Crypto рядом с ciphertext отклонён: он не даёт OS-bound защиты.
- Автоматический запуск PowerShell из HTML невозможен в стандартной browser security model.
- Парольное шифрование файлового режима требует отдельного UX восстановления/ротации и не входит в текущий запрос.
