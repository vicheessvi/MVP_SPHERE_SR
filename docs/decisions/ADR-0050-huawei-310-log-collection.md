# ADR-0050: потоковый экспорт логов Huawei 310

Дата: 2026-11-11. Статус: Bar 310 — подтверждены web-контракт и полный XML-поток, браузерное сохранение ожидает проверки; Box 310/610 — предварительный контракт до отдельных испытаний.

На подключённом Bar 310 после точной проверки модели и устойчивого идентификатора текущий web-bundle показал `reqExportLogUrl="v1/om/log/export"` и POST-вызов. Контрольное чтение вернуло HTTP 200, `application/x-octet-stream` и полный XML `LogModule` до закрывающего тега; сырые данные не сохранялись и не выводились. Метод POST используется производителем для экспорта, не является командой изменения конфигурации. Протокол не переносится без проверки на другие модели.

Адаптер выполняет тот же экспорт лишь после собственных pre/post-auth gates каждой точной 310-модели и совпадения двух маркеров текущего bundle. Ответ проверяется по коду, MIME и XML-префиксу, затем потоково передаётся существующему same-origin механизму сохранения в выбранную пользователем папку. Runtime не хранит копию, а статус не включает содержимое, cookie или токен. Отказ сохранения не превращает JSON-опрос в ошибочный результат и не останавливает остальные устройства. Неподтверждённая схема даёт `protocol_required`.

Для Box 310/610 такой же экспорт подготовлен условно, но `provisional_user_validation` сохраняется до проверки каждой модели администратором. Событийную аналитику 310-журналов не добавлять без отдельного анализа формата.
