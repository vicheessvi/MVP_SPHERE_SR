# ADR-0034: Сверка настроек и граница чтения/изменения

Статус: принято для первого этапа, 2026-10-29.

## Решение

Обычный опрос терминала остаётся read-only. Он добавляет в JSON `deviceSettings` с явными статусами каждого запрошенного поля. Значение `read` разрешено только там, где для точной модели уже подтверждены URL/action, тип ответа, семантика и post-auth identity gate: сейчас Telnet/HTTP у Huawei TE20–TE60 и HTTP у CloudLink Bar 310/Box 310/Box 610. Для остальных параметров и моделей используется `protocol_required` или `not_exposed` без предположения об отключённом состоянии.

Загруженная отдельно XLSX-таблица не изменяет основную SR. Локальный отчёт сохраняет исходные значения и добавляет фактические столбцы только из последнего пригодного JSON, у которого совпадают точный IP имени файла, IP внутри результата и модель. Неуспешный более новый опрос не замещается старым успешным. Сведения «Локальная камера» и «Работы проведены» копируются без оценки.

Изменение настроек выносится в отдельную будущую задачу с модельными write-контрактами, явным opt-in, проверкой модели до записи и post-read. Оно не является частью обычного опроса или формирования XLSX.

Пароль для входа в план нельзя помещать в исходный код публичного репозитория. Администратор согласовал локальный файл на каждом ПК вне Git; проверку должен выполнять Python runtime, а не только клиентский JavaScript. Формат verifier и исключение из запрета постоянного хранения в Constitution требуют отдельного security review. До его завершения текущая граница доступа не ослабляется; клиентская форма сама по себе не считается защитой.

## Причины

Путь к настройке в web-меню не раскрывает её машинный идентификатор и формат ответа. `EnableWifi`/`supportWifi` в существующих ресурсах описывают возможности оборудования, а не включённый радиоинтерфейс. Отсутствие Telnet или SNMP v2 в меню не подтверждает состояние TCP/23 или службы SNMP на конкретном терминале. Публичный hardcoded пароль доступен всем, кто скачает проект, и не может защищать открытый HTML/JavaScript.

## Последствия

Первый XLSX может содержать «Нет данных» для ещё не подтверждённых полей. Их заполнение потребует контрольного read-only исследования каждой точной модели/прошивки и тестов на обезличенных ответах. До этого нельзя заявлять, что все настройки уже фактически проверяются.
