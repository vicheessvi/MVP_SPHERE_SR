# ADR-0038: Отдельное отключение автообновления Huawei TE20

Статус: подтверждено администратором на рабочем ПК после синтетической проверки, 2026-11-02.

## Контекст

Обычный TE20-опрос уже читает `isenableautoupgrade`; администратор сопоставил `0` с отключённым автообновлением в web-меню. Требуется только вариант «Отключить» либо отсутствие изменения. Контракт других моделей и обратное включение не подтверждены.

## Решение

Новый фиксированный action `disable_te20_auto_update` доступен только одному exact TE20 по IP из актуальной SR и не совмещается с закрытием/открытием портов или Answer mode. По умолчанию задача отсутствует. После existing pre-auth/post-auth model и stable identity gates адаптер проверяет маркеры текущего bundle, читает только `isenableautoupgrade` и принимает строго integer 0/1. При 0 — `already_compliant` без записи. При 1 — максимум один `WEB_SaveCfgParamAPI` с единственным `CfgItemInt` и целевым 0, затем точный post-read 0. Неясный исход не повторяется автоматически. Подтверждённое значение выводится в стандартном JSON; секреты и сырые ответы не сохраняются.

## Последствия

Текущий опрос остаётся read-only, старые планы совместимы. Администратор сообщил об успешной проверке отключения автообновления на рабочем ПК; агент отдельно не подключался к устройству и не сохранял сырые доказательства в репозиторий. Никакой перенос на TE30–TE60, CloudLink или Polycom не допускается.
