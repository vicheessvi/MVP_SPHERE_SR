# ADR-0056: Answer mode Huawei CloudLink 300

Дата решения: 2026-11-15. Актуализация: 2026-11-24. Статус: администратор подтвердил Answer mode Bar 300/Box 300/Box 600 в обоих направлениях, по одному IP и массово.

В существующий блок Answer mode плана добавлены варианты «Не менять», «Автоматически» и «Вручную» для exact Bar 300, Box 300, Box 600. Два action ID охватывают группу, но каждая модель сохраняет собственные pre-auth numeric model, post-auth exact model+SN/MAC и contract ID. Один IP либо совместимая группа по фильтрам актуальной SR допустимы только при одном action ID, уникальных IP, верном digest и отдельном согласии. Смешанная группа и совмещение с другими write-задачами блокируются до записи.

У Bar 300 `autoreply=0` означает автоматический ответ, `1` — ручной; это обратная кодировка серии 310. Текущий bundle связывает форму с `WEB_GetCfgParamAPI`, `WEB_SaveCfgParamAPI` и `CfgItemID:"autoreply"`. По отдельным разрешениям администратора выполнен цикл `0→1→0`: каждый переход имел точный pre-read, только одну запись `CfgItemInt` с `autoreply`, пустой `CfgItemString` и точный post-read; пользователь подтвердил оба состояния в web-меню, исходное «Авто» восстановлено. Широкая web-форма сохраняет соседние настройки, но инструмент их не запрашивает и не записывает.

Production action применяется только после model/identity/bundle gates; если значение уже целевое, запись не отправляется. Неясный результат не повторяется автоматически и не считается успехом. Обычный опрос остаётся read-only. На этапе первоначального внедрения Bar write имел `confirmed_local_validation`, Box 300/600 — `provisional_user_validation`; подтверждение только read-only значений и логов не повышало write-статус. Этот предварительный статус заменён отдельным подтверждением ниже. Секреты и сырые ответы не входят в результат, старые JSON не переписываются.

## Эксплуатационное подтверждение 2026-11-24

Для смешанных планов v5 оркестрация расширена ADR-0069: серия 300 может входить
в один запуск с другими подтверждёнными Answer-группами, получая только свой
явно выбранный action. Первоначальный запрет смешанного root плана сохраняется
для v3/v4; собственный vendor-контракт записи серии 300 не меняется.

Администратор отдельно подтвердил изменение Answer mode для Huawei CloudLink
Bar 300, Box 300 и Box 600: «Автоматически → Вручную» и «Вручную → Автоматически»,
отдельно по IP и массово. Это пользовательская эксплуатационная проверка каждой
модели, не автоматический перенос Bar-контроля на Box и не новый live-тест агента.
Новые write-результаты всех трёх exact моделей имеют `confirmed_user_validation`.
Исторические JSON не переписываются. Кодировка, transport, выбранные поля,
model/identity/bundle gates, отдельное согласие и one-write/post-read неизменны;
другие настройки/модели и произвольные прошивки этим подтверждением не охватываются.
