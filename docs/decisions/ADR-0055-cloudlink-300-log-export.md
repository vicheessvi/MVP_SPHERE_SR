# ADR-0055: экспорт логов Huawei CloudLink 300

Дата: 2026-11-13. Статус: успешный сбор Bar 300, Box 300 и Box 600 подтверждён администратором.

Задача продолжает существующий `collectLogs` в модуле «Загрузка данных и опрос устройств»: отдельная папка, timestamp-папка, потоковая передача через loopback, ACK сохранения и ручной импорт уже реализованы. Новый экран, серверный spool и событийный parser не добавляются.

На подключённом exact Bar 300 после pre-auth numeric model 18 и post-auth точной модели с SN/MAC текущий bundle подтвердил кнопку `ExportLogBtn` → `handleExportLogData` → `GET /log?rmd=<nonce>`. Контрольный read-only ответ дал HTTP 200, `application/x-octet-stream`, XML `LogModule`; полный поток затем прочитан порциями и отброшен, закрывающий тег найден. Сырые строки, адрес устройства, учётные данные и файл не сохранены в проект. Это не тест пользовательского сохранения в выбранную папку.

Production opener использует cookie действующего сеанса, HTTPS/443 с проверкой сертификата по умолчанию и только явное разрешение самоподписанного сертификата для текущего запуска. Первые 4096 байт проверяются до передачи в существующий `on_log`; полный файл не буферизуется, результат содержит только безопасный статус. Не используются соседние `WEB_CleanAllLogsAPI`, `WEB_DeleteCHRLogAPI`, `WEB_HIDLogExportRequest`, диагностический архив либо URL серии TE/310.

Box 300 и Box 600 используют общий узкий reader лишь после собственных точных numeric model/identity gates и двух маркеров текущего bundle. Их логи live не проверены. До успешной пользовательской проверки сохранения каждой модели `logCollection.validationStatus=provisional_user_validation` для всех трёх моделей; старые JSON не переписываются. Событийная аналитика по этим журналам требует отдельного исследования и не наследует правила TE или Huawei 310.

Обновление 2026-11-13: администратор подтвердил успешное формирование опросов и файлов логов на всех трёх моделях. Новые `logCollection` получают `confirmed_user_validation`; исторические предварительные файлы не переписываются. Это пользовательская эксплуатационная проверка сбора, не отдельная проверка агентом журналов обеих Box и не подтверждение событийной аналитики. Описанный выше предварительный статус относится к периоду до этой проверки.
