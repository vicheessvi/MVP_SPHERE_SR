# ADR-0019: Проверяемая задача закрытия HTTP и Telnet на Huawei TE40

**Статус**: Принято

**Дата**: 2026-09-06

## Контекст

План автоматического опроса должен по явной галочке закрывать HTTP/80 и Telnet/23. Это write-операция с риском потери управления, поэтому read-only совместимость семейства Huawei недостаточна.

## Решение

- Ввести plan schema v3 с явным `managementTasks`.
- Для write-задачи использовать отдельный загружаемый XLSX структуры SR; не использовать и не изменять основную SR как источник её целей.
- Хранить отдельный список только в памяти, атомарно отклонять некорректные и повторяющиеся IP, а в плане оставлять только безопасную runtime-проекцию и SHA-256 источника.
- Разрешить попытку только exact Huawei TE40 после полного подтверждённого опроса.
- Использовать минимальные firmware-поля `enabletelnet=0`, `enable_http=1` через HTTPS/443.
- Считать успехом post-read значений меню `enabletelnet=0` и `enable_http=1`; TCP listener не входит в критерий результата по решению пользователя.
- Для остальных моделей возвращать `skipped_unsupported`; не делать rollback и не раскрывать session/credentials.

## Последствия

Тестовый TE40 принимает save и повторно сообщает оба значения меню отключёнными. TCP/80 может продолжать отдавать HTTP 200, но это наблюдение находится вне уточнённого scope задачи и не переводит отчёт в ошибку. Расширение write-capability на другие модели по-прежнему требует отдельного evidence review.
