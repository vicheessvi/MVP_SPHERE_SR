# ADR-0046: предварительное чтение настроек Huawei Box 310/610

Дата: 2026-11-10. Статус: реализовано синтетически; эксплуатационная сверка отдельно на Box 310 и Box 610 ожидается.

Box 310 и Box 610 уже используют общее guarded Huawei 310 ядро, но имеют разные exact-model контрактные идентификаторы и независимую проверку модели до отправки credentials и после входа. По запросу администратора общий профиль чтения настроек Bar 310 подключён к обеим Box-моделям условно: каждый точечный запрос разрешён только при маркерах текущего bundle, post-auth identity и строгой схеме ответа. Никакого изменения конфигурации, нового transport или HTTP fallback не добавлено. Отсутствующий маркер даёт `protocol_required`, schema drift — `unavailable`.

Реальные Box bundle и значения ещё не проверены на каждом устройстве. Поэтому новые считанные поля и Site name получают `validationStatus=provisional_user_validation`; HTTP сохраняет существующий статус. Импорт JSON сохраняет предварительные значения для осмотра, но таблица фактических настроек показывает «Требует проверки», а Site name не попадает в подтверждённый отчёт. Неизвестная/неподтверждённая Box модель не наследует профиль.

`autoUpdate` предварительно применяет подтверждённую на Bar семантику возможности обновления прошивки по типу сервера; кодовая схема и отображение UI на Box остаются предварительными. `autoreply`, NTP, Wi‑Fi, SSH и питание также требуют проверки каждой Box отдельно. Пользователь сообщит результаты эксплуатации; подтверждение одной модели не переносится на другую.
