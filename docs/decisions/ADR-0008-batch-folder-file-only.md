# ADR-0008: Пакетный импорт общей папки и единственный файловый режим

**Статус**: принято

**Дата**: 2026-08-10

## Контекст

Результаты автоматизированного опроса передаются как одна общая папка, внутри которой находится несколько каталогов сеансов с JSON. Пользователь требует выбирать общую папку один раз и запускать интерфейс только прямым открытием `index.html`.

## Решение

- Единственная поддерживаемая точка запуска интерфейса — корневой `index.html` по `file://`.
- Состояние интерфейса хранится только в памяти текущей страницы.
- Для каждого JSON выбирается ближайшая родительская папка строгого формата `YYYY-MM-DD_HH-MM-SS`.
- Формат трактуется как `год-месяц-день`; невозможные календарные даты отклоняются.
- Путь папки, а не только её имя, входит в идентичность запуска.
- Группы обрабатываются хронологически; ошибки пути, чтения и разбора изолируются на уровне файла.
- Исходное содержимое, контрольная сумма, имя и относительный путь результата сохраняют provenance.

## Последствия

- Одна операция выбора обрабатывает несколько запусков и вложенные каталоги.
- HTTP/secure marker больше не создаёт второй рабочий режим интерфейса.
- Постоянное хранение и импорт учётных данных в HTML-интерфейсе отсутствуют.
- Исторические loopback/runtime файлы могут оставаться для регрессии и отдельных локальных скриптов, но не являются поддерживаемой точкой запуска UI.
