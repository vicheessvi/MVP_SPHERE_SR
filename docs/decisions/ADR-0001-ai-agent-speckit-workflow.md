# ADR-0001: Workflow ИИ-агент + SpecKit

## Статус

Принято

## Контекст

Проект будет разрабатываться через ИИ-агента. Репозиторию нужен постоянный контекст, предсказуемое выполнение задач и понятное правило, когда использовать Full SpecKit, SpecKit-lite или короткие prompts.

## Решение

- Использовать ИИ-агент + GitHub SpecKit для структурированной разработки.
- Full SpecKit применять для крупных, рискованных или неоднозначных задач.
- SpecKit-lite применять для средних задач.
- Короткие prompts применять для маленьких локальных изменений.
- Держать `AGENTS.md` компактным.
- Хранить долгосрочный контекст в `docs`.
- Хранить спецификации фич в `specs`.
- Фиксировать важные решения через ADR.

## Последствия

- Будущим задачам ИИ-агент потребуется меньше повторяющегося контекста.
- Крупные задачи будут получать спецификацию до реализации.
- Маленькие задачи останутся лёгкими.
- Документацию нужно поддерживать краткой и актуальной.

## Рассмотренные альтернативы

- Только ad-hoc prompting.
- Full SpecKit для каждой задачи.
- Отсутствие постоянной документации.
