# ADR-0020: Общая задача закрытия HTTP/Telnet для Huawei TE30/TE40/TE50/TE60

**Статус**: принято, live-validation TE30/TE50/TE60 ожидается
**Дата**: 2026-09-07

## Контекст

Общий read-only web-CGI алгоритм уже подтверждён для реальных Huawei TE30, TE40, TE50 и TE60. Задача изменения `enabletelnet` и `enable_http` была подтверждена на TE40. Пользователь потребовал применить этот же алгоритм к остальным трём exact-моделям.

## Решение

Единственная capability `disable_insecure_management_services` разрешается ровно для TE30, TE40, TE50 и TE60. Перед записью остаются обязательными exact-IP allowlist, явный opt-in, отдельный XLSX целей, совпадение модели до и после входа, подтверждение identity, наличие action/config markers и успешное чтение обоих значений по ожидаемой схеме.

Разрешён только минимальный payload `enabletelnet=0`, `enable_http=1`. Успех подтверждается повторным чтением этих значений из меню кодека. TCP listener не входит в критерий. Любая неизвестная модель, несовпадение модели, schema drift или отсутствие markers завершается без записи.

## Последствия

- TE30/TE50/TE60 используют ту же реализацию, что TE40; модельные копии алгоритма не создаются.
- Каталог, интерфейс и Python runtime имеют единый exact-model allowlist.
- Синтетические contract tests покрывают все четыре модели.
- До контролируемой проверки на реальных TE30/TE50/TE60 их write-совместимость считается provisional и не должна описываться как подтверждённая эксплуатацией.
