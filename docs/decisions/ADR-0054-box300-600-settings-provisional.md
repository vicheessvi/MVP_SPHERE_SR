# ADR-0054: предварительное чтение настроек Box 300/600

Дата: 2026-11-13. Статус: эксплуатационная проверка обеих Box подтверждена администратором.

Администратор сообщил, что Huawei CloudLink Box 300 и Box 600 по новым параметрам аналогичны проверенному Bar 300. Поэтому существующие узкие read-only CGI readers feature 051 применяются к каждой exact Box-модели, но только после её собственного numeric pre-auth кода (19 для Box 300, 22 для Box 600), текущих bundle-маркеров и post-auth точной модели с устойчивым SN либо MAC. Разные model-key, transport и contract ID сохраняются; это единая реализация чтения, а не отключение модельных границ.

Новые `deviceSettings` обеих Box имеют `validationStatus=provisional_user_validation`, как и каждый `status=read` факт. Локальный импорт принимает факт только при точном совпадении модели, разрешённого источника и согласованных общему полю/полю маркеров проверки; до контрольных опросов аналитика показывает «Требует проверки». Ранее подтверждённые обычные опросы и Site name Box 300/600 своего статуса не теряют, старые JSON не переписываются. У `snmpV2` пока нет уточнённой причины `version_not_supported` для Box: отсутствие v2 у Bar 300 не доказывает это машинно на каждой Box.

Не добавляются команды записи, HTTP fallback, широкий конфигурационный запрос с логинами/паролями, REST-контракт серии 310 либо новые модели. На реальном Box 300 и отдельно Box 600 нужно сверить HTTP, Telnet, SSH, автоответ, NTP, Wi‑Fi, тип сервера и питание с меню; после этого можно повысить статус новых полей отдельно по каждой модели.

Обновление 2026-11-13: администратор подтвердил успешные опросы Box 300 и Box 600 и совпадение новых значений с меню каждой модели. Новые read-only `deviceSettings` обеих Box теперь имеют `confirmed_user_validation`; исторические JSON с предварительным маркером сохраняют его. Выше описано состояние решения до этой проверки. Модельные gates и ограничения записи не меняются.
