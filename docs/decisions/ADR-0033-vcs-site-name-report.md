# ADR-0033: локальная таблица и XLSX Site name терминалов ВКС

Дата: 2026-10-27. Статус: реализовано локально, ожидает пользовательской проверки.

В модуле «Оборудование → Терминалы ВКС» добавлен второй вид существующего перечня. Он получает тот же набор устройств после текущих фильтров, включая выбранную пользователем актуальность SR. Сведения об устройстве и локации берутся из соответствующей карточки SR, а Site name — из самого нового привязанного результата опроса устройства. При неуспешном или неполном последнем результате старое значение не подставляется, чтобы не выдавать его за актуальное. Исходные SR и JSON не изменяются.

Таблица и скачиваемый XLSX строятся из одного набора строк и семи фиксированных столбцов. Vendored SheetJS создаёт файл в памяти текущей вкладки; браузер скачивает его локально без обращения к серверу или внешнему сервису. Все значения экспортируются как текст, включая IP, MAC и строки, похожие на формулы. Прямой `index.html` и Python loopback-режим используют один и тот же интерфейс. Новый маршрут не добавляется; Справочник получает описание возможности из `product-catalog.js`.

Решение и критерии приёмки: `specs/032-vcs-site-name-report/spec.md`.
