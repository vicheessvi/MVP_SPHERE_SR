# ADR-0039: Трёхпозиционное управление SSH Huawei TE20

Статус: синтетически реализовано, реальная write-проверка ожидается, 2026-11-02.

После подтверждённого чтения `enable_ssh` на exact TE20 добавлены только два фиксированных write-action: `1` включить и `0` отключить. Пустой выбор не создаёт действия. Только один TE20 по IP из текущей SR, отдельное согласие администратора, pre-auth/post-auth model и stable identity gates. Перед записью читается строгое бинарное значение; уже целевое значение не записывается. Иначе максимум один однополевой запрос с текущим CSRF и точный post-read. Неясную запись не повторять автоматически. С другими write-задачами SSH не совмещается. Отключение может прекратить удалённое управление; UI предупреждает. Live запись и сверка меню — отдельный этап; другие модели не наследуют этот контракт.
