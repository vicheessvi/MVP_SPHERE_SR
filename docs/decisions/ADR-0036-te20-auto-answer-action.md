# ADR-0036: Отдельное изменение автоответа Huawei TE20

Статус: подтверждено контролируемой записью и сверкой web-меню, 2026-10-30.

Обычный опрос остаётся read-only. Взаимоисключающие задачи `set_te20_auto_answer_automatic` и `set_te20_auto_answer_manual` могут запускаться только администратором на одном exact Huawei TE20, выбранном по IP из актуальной SR. Они не совмещаются с закрытием HTTP/Telnet и требуют отдельного подтверждения перед запуском.

После существующей pre-auth и post-auth проверки модели и устойчивого идентификатора адаптер проверяет текущий bundle и читает `autoreply`. Допустимы только коды `1` («Вручную») и `0` («Автоматически»). Если текущее значение совпадает с выбранным, запись не нужна. Иначе отправляется максимум один `WEB_SaveCfgParamAPI` с единственным `CfgItemInt` для целевого `autoreply=0` либо `1`; успех фиксируется только при точном повторном чтении. Неизвестная схема, модель или результат блокируют/помечают действие как неуспешное. Восстановление не повторяет неясную запись автоматически.

Контролируемые изменения на реальном TE20 дали `1 → 0` и `0 → 1`; оба подтверждены повторным машинным чтением, автоматический режим также подтверждён администратором в web-меню. Остальные параметры и другие модели не выводятся из этого опыта и требуют отдельной проверки.
