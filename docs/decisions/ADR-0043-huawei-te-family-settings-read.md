# ADR-0043: чтение настроек Huawei TE30/40/50/60

Дата: 2026-11-06. Статус: принято для read-only опроса; TE30/50/60 ожидают эксплуатационной проверки.

Обычный JSON-опрос TE-семейства ранее создавал семь ключей настроек, но фактически читал только Answer Mode, HTTP и Telnet. После отдельного контролируемого HTTPS-сеанса exact TE40 подтверждены текущие маркеры и схемы чтения общих параметров, а также отдельные `WEB_GetSnmpCfgAPI` и `WEB_GetWifiStatModeAPI`. Оба специальных запроса возвращают данные только при сеансовом CSRF. SNMP-ответ содержит чувствительные поля: сохраняются только статус SNMPv2 и признак активности SNMP, без community, паролей и raw payload. Wi-Fi `ucWifiMode` принимает подтверждённые текущим web-кодом режимы: 0 выключен, 1 точка доступа, 2 клиент, 3 оба.

Для питания принимается доступное `sleepTime`; если маркер расписания отсутствует, о расписании вывод не делается. Каждое поле имеет независимый marker/schema gate и неизвестный статус при отказе. TE20 и write-контракты не меняются. На текущем TE40 все семь групп подтверждены повторным read-only опросом; перенос на TE30/50/60 условен и требует отдельных результатов пользователя. Сырые ответы, инфраструктурные адреса и credentials не помещались в Git.
