# ADR-0066 — зарегистрированное выключение ВКС независимо от инициатора

Дата: 2026-11-24. Статус: принято по явному одобрению администратора.

## Основание

Администратор обнаружил пропуски команд от контроллера и утвердил общее правило:
команда Shut down терминала учитывается как выключение, без обязательного
Web/пульта. Также утверждены исключения ошибки/отмены/настроек/компонентов,
дедупликация и отсутствие догадки об инициаторе. Это семантическое правило аудита,
а не доказательство аварийной потери электричества.

## Решение

Общий bounded helper `vcs-shutdown.js` работает только внутри известных Huawei
TE/310/300 форматов и существующих exact model/IP/SR gates. Неизвестный модуль
журнала больше не исключает команду; строка должна описывать выключение самого
терминала. Присутствие слова success не обязательно, явные отрицательные/
служебные контексты исключаются. Старый Terminal powered off сохраняется.
Инициатор not_established; совместимые Web/remote_control — канал, не пользователь.
Нового vendor API, transport или write нет.

Следующий известный запуск после команды — start_after_shutdown, не новый
confirmed_reboot/предполагаемая потеря питания. Для наблюдений в разных файлах
новый native publish выполняет потоковую межфайловую связь; исходная классификация
и gap сохраняются в безопасном _shutdownLink, чтобы поздний промежуточный запуск
мог отменить прежнюю связь. Равные timestamps не дают межфайлового порядка.

## Старые данные

Parser versions подняты отдельно по моделям; registry содержит analysisRuleset и
analysisRuleVersion, checkpoint scope/key включает версию. Старые results не
переиспользуются как новые. Администратор выбирает полную прежнюю папку; старые
источники без корректного повторного разбора блокируют replacement publish.
Готовые новые scans сохраняются по файлам и восстанавливаются после остановки,
до двух Worker/1 МиБ чтение, скорость по физическим байтам. Предыдущая ревизия
доступна до успешного atomic finish. БД не содержит сырого журнала, поэтому новые
команды не восстанавливаются из неё без повторного чтения оригиналов.

## Подтверждение и пределы

Синтетические проверки известных форматов/всех 11 Huawei model gates, raw File и
text, негативные контексты, дубли, неизвестный инициатор, same/split-file startup,
late insertion и restart upgrade. Реальное подключение к устройству и реальные
строки администратора для этой правки не использовались; образец предоставить
невозможно. Новое правило утверждено пользователем, это не новый live vendor test.
По отдельному сообщению администратора Polycom RPG отложен до подключения.
TGZ/неизвестные форматы остаются metadata-only, контракт не угадывается.
