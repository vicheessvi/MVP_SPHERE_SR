# ADR-0049: массовый Answer mode по фильтрам SR

Дата: 2026-11-10. Статус: реализовано синтетически; реальная массовая запись не выполнялась.

По уточнению администратора задачи Answer mode exact TE20, TE30/40/50/60 и Bar 310/Box 310/Box 610 разрешены как для одного IP, так и для набора, выбранного каскадом фильтров актуальной SR. Ранее все три группы были ограничены single-IP; этот предел снят только для Answer mode. HTTP, NTP, SSH, питание и иные write-задачи сохраняют прежние ограничения.

Один план содержит ровно один модельный action ID. Перед созданием и повторно в Python runtime проверяются SR digest, режим выбора, непустой набор уникальных IP и совместимость каждой выбранной модели с action. Смешанная либо неподдерживаемая группа целиком блокируется до сетевой записи, а не молча сокращается. UI показывает число затронутых устройств и предупреждает об изменении входящих вызовов; требуется отдельное согласие.

Устройства обрабатываются существующим последовательным polling job с интервалами и независимыми JSON-результатами. На каждом остаются прежние model/identity/bundle/pre-read/one-write/post-read gates. Отказ или неясный исход одной записи не становятся успехом и не повторяются автоматически; другие устройства продолжают опрашиваться. Никаких реальных массовых изменений в рамках разработки не выполнялось.
