# ADR-0005: Защищённый локальный runtime и credential vault

## Статус

Принято, 2026-08-10. Заменяет ADR-0003 как постоянный runtime для чувствительных данных. Способ подготовки Node.js уточнён ADR-0006; непостоянный прямой запуск ограничен ADR-0007.

## Контекст

Browser-only `localStorage` имеет квоту, читается browser profile/DevTools и не подходит для защищённого хранения файлов и паролей. Продукту нужны локальная аналитика, отсутствие внешней передачи, единственная роль и подготовка к реальному опросу устройств.

## Решение

- Запускать встроенный Node.js HTTP runtime только на `127.0.0.1` и случайном порту.
- Создавать доступ одноразовым launch token и in-memory session с HttpOnly/SameSite cookie.
- Защищать мутации проверкой Host, Origin и custom CSRF header; запрещать CORS и внешние источники CSP.
- Шифровать каждый объект AES-256-GCM; защищать случайный мастер-ключ Windows DPAPI CurrentUser.
- Хранить credential vault отдельно и не предоставлять read API, экспорт или backup секретов.
- Убрать прикладную quota; использовать atomic replace и сообщать `ENOSPC` без повреждения предыдущего объекта.
- Разрешать polling только для explicit plan allowlist и валидных unicast IP.
- Без подтверждённого vendor contract возвращать `protocol_required` и не обращаться к credentials.
- Оставить только роль «Администратор МЦТП» и целевые маршруты Dashboard/VCS/Controllers/Panels/Upload/Storage.

## Последствия

- Прямой `index.html` разрешён ADR-0007 только как непостоянный сеанс без browser storage, credential import и сетевого polling; для постоянных рабочих данных и vault нужен `start.ps1`.
- Данные привязаны к текущему Windows-пользователю; перенос требует отдельно спроектированного защищённого экспорта.
- Нет искусственного лимита объёма, но остаются физические ограничения диска, RAM и ОС.
- Исходный plaintext credentials-файл остаётся ответственностью пользователя до/после импорта.
- Компрометация текущей Windows-сессии или памяти процесса находится вне защищаемой границы.
- Vendor adapters требуют отдельной спецификации и security-тестов.

## Альтернативы

- `localStorage`/IndexedDB: отклонено из-за quota и слабой границы секретов.
- Общая plaintext SQLite/JSON: отклонено из-за чтения данных на диске.
- Облачный backend: отклонено требованием полной локальности.
- Жёстко заданный общий пароль/ключ: отклонено из-за невозможности безопасной поставки и ротации.
- Выдуманные HTTP/SSH/SNMP запросы: отклонено как небезопасное и недостоверное поведение.
