# ADR-0013: автоматический опрос внутри локального инструмента

**Статус**: принято

**Дата**: 2026-09-01

## Контекст

Пользователь потребовал запускать web-опрос сразу после формирования плана внутри интерфейса и сохранять каждый готовый JSON в новую timestamp-папку выбранного общего каталога. Direct `file://` не имеет полномочий запускать Node/ping, читать Extron API через CORS/self-signed TLS и получать абсолютный путь записи.

## Решение

1. `start.ps1` запускает существующий Node runtime только на `127.0.0.1` и открывает одноразовый launch URL.
2. Mutation API требует HttpOnly session cookie, точный Host, same-origin Origin и CSRF token.
3. UI передаёт бинарный XLSX endpoint текущей сессии. Runtime проверяет `Логин | Пароль`, SHA-256 и держит пары только в памяти одного job.
4. Сформированный plan v2 автоматически передаётся runtime; один session выполняет не более одного job.
5. Extron остаётся HTTPS-only. Явный per-job флаг допускает самоподписанный сертификат без глобального отключения TLS validation; HTTP fallback запрещён.
6. Browser выбирает общий output через File System Access API. Runtime выдаёт один redacted result и ждёт ACK успешной записи; только затем runner начинает interval.
7. Внутри общей папки создаётся уникальная `YYYY-MM-DD_HH-mm-ss`, JSON совместимы с существующим ручным импортом.
8. После completed/cancelled/failed credential pool очищается. План, status, JSON, логи и persistent store не содержат secrets.

## Последствия

- Автоматический режим требует запуска через `start.ps1` и открытой вкладки Chromium до завершения job.
- Прямой `index.html` остаётся для ручного импорта и аналитики, но честно блокирует автоматический сетевой запуск.
- Пользовательские JSON находятся только в явно выбранной папке под правами Windows; приложение не создаёт дополнительную runtime-копию.
- Self-signed HTTPS шифрует трафик, но не подтверждает подлинность устройства; это явное временное ограничение текущей сети.

## Отклонённые варианты

- Browser polling из `file://`: недоступен из-за sandbox, CORS и TLS.
- Обычный HTTP: раскрывает Basic credentials в локальной сети.
- Credentials в plan/status: создают сериализуемую утечку.
- ZIP после всего batch: теряет результаты при промежуточном сбое.
- Постоянный Windows service/Electron: несоразмерно расширяют установку и поверхность атаки.
