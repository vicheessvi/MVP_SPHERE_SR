# ADR-0041: Управление питанием Huawei TE20

Статус: реализовано по live read-only web-bundle и синтетическим тестам; реальная запись ожидается, 2026-11-05.

Действующий exact TE20 подтвердил чтение пяти полей питания. Текущий web-bundle показал отдельные числовые поля `suppotReboot`, `sleepTime`, `enableTimeReboot`, `rebootHour`, `rebootMinute`, сохранение через `WEB_SaveCfgParamAPI` и точный список сна 0/1/5/10/15/30/60 минут. Реальный IP, значения устройства и credentials в репозиторий не добавлялись.

Один opt-in action доступен только одному TE20 по IP из текущей SR. Каждое поле имеет «Без изменений» по умолчанию; включение планового перезапуска требует явного времени. После прежних model/identity gates, marker/schema checks и точного pre-read выполняется максимум одна запись только отличающихся полей и post-read всех пяти. Успех без post-read запрещён, неопределённая запись не повторяется автоматически. «Shut Down/Restart» — настройка меню, а не команда немедленной перезагрузки. Плановый перезапуск может привести к автоматической перезагрузке, поэтому UI отдельно предупреждает.

Контракт не переносится на другие модели; live write остаётся отдельной контролируемой проверкой с точными целевыми значениями.
