# Документация

Эта папка хранит долгосрочный контекст проекта для ИИ-агента и команды.

## Основные файлы

- `../AGENTS.md` — постоянные инструкции для ИИ-агента
- `project-vision.md` — видение продукта и рамки MVP
- `architecture.md` — фактические архитектурные заметки
- `context-map.md` — карта контекста для экономной работы ИИ-агента
- `development-workflow.md` — канонический workflow разработки
- `decisions/` — архитектурные решения
- `implementation-log.md` — журнал значимых изменений
- `../specs/` — спецификации фич
