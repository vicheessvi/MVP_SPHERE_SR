# Контракт Huawei CloudLink Bar 300 / Box 300 / Box 600

Статус на 20.10.2026: read-only Bar 300 включён и проверен на подключённом устройстве; администратор подтвердил отчёты Box 300/600 и совпадение их Site name с меню. Подробности и границы — в `specs/030-huawei-cloudlink-300-polling/` и `docs/decisions/ADR-0031-huawei-cloudlink-300-polling.md`.

Администратор 20.10.2026 вручную подтвердил, что параметр собственного имени терминала находится по пути `Настройки → Графический экран → Имя сайта (Site name)` для CloudLink Bar 300, Box 300 и Box 600. При создании контракта значение нужно считывать с устройства и помещать в `siteName.value` и `webBlocks.Device Info.Site Name` готового JSON; название локации SR не является заменой.

Путь в меню сам по себе не устанавливал сетевой протокол. Контролируемый Bar 300 подтвердил отличающийся от серии 310 legacy CGI, exact pre-/post-auth identity, шесть ресурсов и точный `sitename` read. Box 300/600 используют общий core лишь при отдельных exact-модельных проверках; их эксплуатационный результат подтверждён пользователем. Контракт Bar/Box 310 на серию 300/600 не переносится.
