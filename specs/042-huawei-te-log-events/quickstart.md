# Quickstart / acceptance

1. Загрузить текущую SR, затем через «Импортировать папку логов» выбрать общую папку с вложенными папками запусков.
2. Открыть «Анализ перезагрузок устройств»: сохранить прежнюю Extron-область и увидеть отдельные Huawei-перезагрузки, отключения и запуски с неизвестной причиной.
3. Повторно импортировать ту же папку: счётчики не должны удвоиться. Проверить фильтры по модели, локации и адресу.
4. Проверить неизвестный IP, дубликат IP в SR, архив, повреждённую строку и неподтверждённую модель: событие не создаётся.
5. Запустить `node tests.js`, `node scripts/validate-reference.js`, `node --check app.js`; Python-регрессию на предмет побочного эффекта.
6. Для TE20 проверить, что `System boot` без web `reboots` остаётся неизвестным запуском, а контролируемая пара web `reboots` → новый boot даёт одну перезагрузку. Отдельный web `shut ... down ... terminal` после штатного выключения даёт одно событие отключения; `OFFLINE` не учитывается и аварийная потеря питания не утверждается.
7. После выключения TE20 с пульта проверить отдельный `LOG_MOD_RC` маркер, новое событие отключения со способом «Пульт ДУ» и отсутствие события от одних лишь нажатий Power/сна.
8. При паузе от 60 минут перед запуском без известной причины проверить отдельный раздел «Предполагаемые отключения питания» с низкой достоверностью; изменение порога должно переводить событие обратно в неизвестные запуски. Пауза без запуска, штатное выключение и скачок часов не должны становиться предположением. Подтверждённые счётчики не меняются.
