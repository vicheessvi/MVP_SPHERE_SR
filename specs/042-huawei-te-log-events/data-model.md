# Data Model

- `LogImportRow`: существующие локальные метаданные файла, точный IP, формат и статус сопоставления с текущей SR.
- `TeLogMarker`: тип `system_start | reboot_marker | power_off`, локальное время устройства, номер строки; без сырого сообщения.
- `TeLogEvent`: `confirmed_reboot | power_off | unknown_start`, deviceId, локальное время, файл и номер строки, модель/локация/адрес по актуальной SR, идентификатор правила.
- `Coverage`: число прочитанных, исключённых, неоднозначных файлов/строк и событий.
- Дубликаты события из повторных выгрузок объединяются по exact deviceId + тип + локальное время; исходные файлы не меняются.
