# Contract: Huawei TE log event extraction

Только файл `<IP>.xml` с `LogModule` и единственным точным соответствием SR-модели TE30/TE40/TE50/TE60. Чтение частями через browser File API, UTF-8 decoder, одна строка не длиннее 8192 символов; XML как дерево не парсится. Встречаются только допустимые модули `LOG_MOD_MC` и `LOG_MOD_BSP`, строгая локальная дата/время `YYYY-MM-DD HH:mm:ss` и ограниченный номер записи.

- `LOG_MOD_MC` + `System start` → маркер запуска.
- `LOG_MOD_MC` + `normal ... reboot` → явный признак перезагрузки; подтверждённое событие только при связанном запуске в пределах двух минут, один запуск — максимум одно событие.
- `LOG_MOD_BSP` + `Terminal ... powered ... off` → явное зафиксированное отключение.
- Прочие слова power и неясные запуски не становятся перезагрузкой или отключением; неясные запуски показываются отдельно.

Время без часового пояса остаётся локальным временем терминала. Сырой текст, токены и credentials не входят в производные события. Разбор TE30/50/60 условен по точному формату; иные модели не наследуют правило.
