# Research: Answer mode CloudLink 300

## Актуальный статус — 2026-11-24

Администратор отдельно подтвердил изменение Answer mode для Huawei CloudLink Bar 300, Box 300 и Box 600
в обоих направлениях, отдельно по IP и массово. Новые write-результаты имеют
`confirmed_user_validation`; исторические JSON сохраняют прежний статус.
Это пользовательская эксплуатационная проверка, а не независимый live-тест
агента всех моделей/прошивок. Ниже сохранены исходные исследования и первоначальные
ограничения; их предварительный статус заменён данным подтверждением, но
model/identity/bundle/HTTPS gates и запрет повтора неясной записи остаются.


## Подтверждено

- Read-only Bar 300 `autoreply=0` означает «Автоматически», `1` — «Вручную» по ранее выполненному ручному циклу администратора; текущее чтение после exact model/identity снова показывает «Авто».
- Текущий Bar 300 bundle содержит `SelectAutoreply` с вариантами 0/1, config-группу с `autoreply`, `CfgItemID:"autoreply"` в сохранении и `WEB_SaveCfgParamAPI`. Форма web-интерфейса сохраняет также соседние параметры конференции; инструмент должен отправлять только один `CfgItemInt`.
- Существующий план Answer mode для TE/310 уже поддерживает одиночный IP и совместимые фильтры SR, проверку digest/уникальных IP/моделей, запрет совмещения write-задач и отдельное подтверждение.
- Кодировка серии 310 обратная (`1=Авто`), поэтому её REST write нельзя переносить на серию 300.

## Открытый evidence review

- После отдельного согласия администратора exact Bar 300 прошёл pre-auth numeric и post-auth model/identity gates; текущий bundle подтвердил форму и save-маркеры. Узкий pre-read дал `autoreply=0`, одна запись `WEB_SaveCfgParamAPI` только с `CfgItemInt=[autoreply=1]` и пустым `CfgItemString` была принята, точный post-read дал `autoreply=1`. Это машинное подтверждение «Авто → Вручную»; web-меню ожидает сверки администратора. Повтора записи не было.
- После отдельного согласия администратора обратный контролируемый переход прошёл тем же узким контрактом: exact model/identity, pre-read `autoreply=1`, одна запись только `autoreply=0`, принятый ответ и точный post-read `autoreply=0`. Исходное «Авто» восстановлено; администратор подтвердил его также в web-меню после обновления.
- Box 300/600 не проверены write; их статус должен оставаться предварительным при подготовке к эксплуатации.

## Решение до закрытия неизвестного

Оба направления минимальной записи и возврат исходного «Авто» подтверждены машинно без повтора. Production write допустим после синтетических fail-closed тестов, точного каталога моделей и UI-подтверждения; для Box 300/600 write-статус остаётся предварительным. При отсутствующем маркере/схеме — безопасный отказ до записи, без автоматического повтора.
