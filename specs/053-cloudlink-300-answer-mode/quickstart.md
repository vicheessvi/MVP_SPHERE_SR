# Проверка Answer mode CloudLink 300

1. На тестовом Bar 300 в меню подтвердить исходный «Авто». Дать отдельное разрешение на один переход в «Вручную»; инструмент должен проверить точную модель и исходный код 0, отправить не более одной минимальной записи `autoreply=1` и повторно прочитать 1.
2. Сверить web-меню после обновления. Отдельным разрешением вернуть «Авто», подтвердить pre-read 1, единственную запись 0 и post-read 0; исходное состояние восстановлено.
3. В существующем разделе «План автоматического опроса» проверить три варианта нового Answer mode рядом с остальными. «Не менять» не создаёт action.
4. Для одного IP и совместимой группы SR проверить число целей, отдельное подтверждение записи, запрет смешанной группы и конфликтующих задач до сети.
5. Проверить неизвестный bundle, код, модель, идентификатор, timeout и неясный write: нет ложного успеха и автоматического повтора, результат не содержит секретов.
6. Box 300 и Box 600 испытать отдельно на рабочих устройствах; до этого их write-результаты предварительные, даже если обычные опросы/логи подтверждены.
