# Feature Specification: Управление питанием Huawei TE20

**Branch**: `codex/secure-local-runtime`
**Date**: 2026-11-05
**Status**: Implemented; confirmed by administrator on work PC

## User Scenarios & Testing

### User Story 1 — Независимый выбор параметров (Priority: P1)

Администратор выбирает один exact TE20 по IP из текущей SR и отдельно задаёт «Shut Down/Restart», сон и плановый перезапуск либо оставляет каждый параметр без изменений.

**Independent Test**: Все «Без изменений» сохраняют read-only опрос; каждый непустой выбор формирует одно действие с точными выбранными полями.

**Acceptance Scenarios**:

1. «Shut Down/Restart» — «Без изменений», «Включить», «Отключить».
2. Сон — «Без изменений», «Никогда» либо один из подтверждённых интервалов 1/5/10/15/30/60 минут.
3. Плановый перезапуск — «Без изменений», «Включить», «Отключить»; включение требует точного времени в формате 24-часового `HH:MM`, изменение времени при выключенном расписании запрещено.
4. Массовый режим, другая модель и совмещение с другими задачами записи блокируются до сети.

### User Story 2 — Проверяемый результат (Priority: P1)

Перед записью система подтверждает модель и идентичность, читает пять фактических полей и сохраняет только выбранные изменения одним запросом, затем читает их повторно.

**Independent Test**: Синтетические ответы проверяют no-op, одно поле, несколько полей, неизвестный код, ошибку записи и несовпавший post-read.

### Edge Cases

- Включение планового перезапуска может вызвать автоматическую перезагрузку в установленное время; требуется отдельное явное подтверждение.
- Настройка «Shut Down/Restart» не является командой немедленной перезагрузки.
- Неясный исход записи не повторяется автоматически.

## Requirements

- **FR-001**: Каждое поле по умолчанию «Без изменений».
- **FR-002**: Один exact TE20 из SR, отдельное подтверждение и запрет сочетания с другими write-задачами.
- **FR-003**: Допустимы только значения сна из текущего подтверждённого списка и время 00:00–23:59.
- **FR-004**: Успех возможен только после exact post-read всех пяти полей, максимум одна запись.
- **FR-005**: Обычный опрос остаётся read-only; другие модели не наследуют действие.

## Success Criteria

- **SC-001**: При всех «Без изменений» нет сетевой записи.
- **SC-002**: Во всех тестах изменения выполняется не более одной записи только выбранных полей.
- **SC-003**: Неверная модель/схема/время и несовпавшее повторное чтение не дают успешного статуса.
- **SC-004**: Регрессии прежних опросов проходят.

## Assumptions

- Точная модель TE20 и текущая прошивка дают подтверждённый read-only контракт. Web-bundle содержит значения сна 0/1/5/10/15/30/60 и отдельные числовые поля расписания. Позднее администратор сообщил об успешной проверке всех новых действий питания на рабочем TE20.
