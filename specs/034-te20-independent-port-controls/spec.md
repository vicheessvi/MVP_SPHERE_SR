# Feature Specification: Независимое управление HTTP и Telnet на Huawei TE20

**Feature Branch**: `codex/secure-local-runtime`
**Created**: 2026-11-02
**Status**: Implemented; pending live validation
**Input**: Администратор выбирает отдельно для HTTP и Telnet: открыть, закрыть или оставить без изменений.

## User Scenarios & Testing

### User Story 1 — Независимый выбор портов (Priority: P1)

Администратор выбирает один точный Huawei TE20 по IP из актуальной SR и для HTTP и Telnet независимо задаёт «Не менять», «Открыть» или «Закрыть».

**Why this priority**: Текущая объединённая задача умеет только закрывать оба сервиса.

**Independent Test**: Для всех девяти сочетаний двух трёхпозиционных полей проверить состав плана и отсутствие команды для «Не менять».

**Acceptance Scenarios**:

1. Given оба поля «Не менять», when создан план, then задача записи отсутствует и выполняется обычный опрос.
2. Given HTTP «Открыть» и Telnet «Не менять», when создан план, then разрешена только запись HTTP; Telnet не записывается.
3. Given HTTP «Не менять» и Telnet «Закрыть», when создан план, then разрешена только запись Telnet; HTTP не записывается.
4. Given оба параметра выбраны, when создан план, then каждый выполняется и проверяется отдельно.

### User Story 2 — Проверяемое изменение (Priority: P1)

Администратор получает результат по каждому выбранному порту: уже установлен, изменён и подтверждён либо ошибка без автоматического повтора неопределённой записи.

**Why this priority**: Ошибочное открытие сервиса снижает безопасность устройства.

**Independent Test**: Синтетические ответы на чтение, запись, отсутствие маркера и ошибку post-read проверяют fail-closed поведение.

**Acceptance Scenarios**:

1. Given точная модель и подтверждённая идентичность, when текущее значение отличается от целевого, then выполняется максимум одна запись конкретного поля и точное повторное чтение.
2. Given целевое значение уже установлено, when выполняется задача, then запись не отправляется.
3. Given модель, схема или ответ не подтверждены, when выполняется задача, then запись не отправляется или результат помечается ошибкой.

### Edge Cases

- Если первый параметр изменён, а второй не прошёл проверку, результат каждого сохраняется отдельно; автоматического отката нет.
- При прерывании после неясного результата записи повторная запись автоматически не выполняется.
- Новые команды недоступны для других моделей; существующая задача закрытия остаётся без изменений.
- Открытие HTTP не означает переход инструмента на обычный HTTP: сетевой опрос остаётся HTTPS.

## Requirements

### Functional Requirements

- **FR-001**: Система MUST предоставлять независимые три варианта для каждого порта, по умолчанию «Не менять».
- **FR-002**: Система MUST ограничить новые действия одним exact Huawei TE20 по IP из текущей SR и требовать отдельного подтверждения администратора.
- **FR-003**: Система MUST не посылать команду для варианта «Не менять».
- **FR-004**: Система MUST выполнить pre-read, максимум одну запись одного параметра и post-read для каждого выбранного порта после проверки модели и идентичности.
- **FR-005**: Система MUST раздельно показывать результат HTTP и Telnet; успешный ответ на запись без подтверждённого post-read не считается успехом.
- **FR-006**: Система MUST сохранять обычный опрос read-only и не смешивать новые действия с прежним групповым закрытием или изменением автоответа.
- **FR-007**: Система MUST не передавать учётные данные, ответы устройства или данные SR вне локального компьютера.

### Key Entities

- **Выбор параметра**: порт и целевое состояние либо «Не менять».
- **Результат действия**: идентификатор порта, статус, факт попытки записи, безопасные значения до/после и код ошибки.

## Success Criteria

### Measurable Outcomes

- **SC-001**: Администратор может задать все девять сочетаний значений двух полей; вариант «Не менять» ни разу не вызывает запись.
- **SC-002**: В проверках 100% записей ограничены ровно одним выбранным параметром и сопровождаются повторным чтением.
- **SC-003**: В 100% сценариев неизвестной модели, схемы или ошибочного post-read успех не показывается.
- **SC-004**: Существующие сценарии опроса и группового закрытия сохраняют результат регрессионных проверок.

## Assumptions

- Текущий запрос относится к подключённому Huawei TE20; другие модели требуют собственного подтверждённого write-контракта.
- Значения включения/выключения принимаются только из ранее подтверждённого бинарного чтения TE20; реальная эксплуатационная проверка открытия остаётся отдельным этапом.
- Упоминание «порт» в интерфейсе относится к настройке web-меню, а не проверке TCP listener.
