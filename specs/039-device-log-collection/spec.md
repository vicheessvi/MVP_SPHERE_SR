# Feature Specification: Локальный сбор и импорт логов устройств

**Branch**: `codex/secure-local-runtime`
**Date**: 2026-11-05
**Status**: Implemented; pending full live TE20 workflow validation

## User Scenarios & Testing

### User Story 1 — Независимые режимы JSON и логов (Priority: P1)

Администратор выбирает один из трёх режимов: только JSON, только логи или оба. Для логов выбирается отдельная общая папка, в которой создаётся папка времени запуска. Режим только логов не создаёт JSON-файлы опросов и не требует папку JSON.

**Independent Test**: Запуск с и без опции, одной и несколькими целями; файлы попадают только в явно выбранную папку логов, JSON — в прежнюю папку результатов.

**Acceptance Scenarios**:

1. По умолчанию формируются только JSON; запрос к логам и папка логов отсутствуют.
2. Если выбран только сбор логов, папка JSON не требуется и файлы опроса JSON не создаются; служебный журнал продолжения остаётся в папке логов.
3. Если оба варианта выключены или для выбранного варианта не указана папка, запуск блокируется до сети.
4. Exact TE20 и TE30/40/50/60 выгружают исходный XML потоком в timestamp-папку только по собственным подтверждённым маркерам; TE30/50/60 ожидают проверки пользователя, остальные модели получают «не поддерживается» без попытки угадать URL.
5. Ошибка загрузки или записи отдельного лога отмечается безопасно и не останавливает другие устройства.

### User Story 2 — Ручной импорт и первичная аналитика (Priority: P1)

Администратор выбирает общую папку логов целиком, включая вложенные timestamp-папки. Инструмент показывает число и суммарный размер файлов, распределение по типам, устройство по точному IP и проблемы формата/сопоставления. Исходные файлы не переписываются.

**Independent Test**: Папка с несколькими запусками, TE20 XML, текстом, архивом и неизвестным файлом даёт предсказуемые метаданные без исполнения содержимого.

### Edge Cases

- Лог может содержать чувствительные инфраструктурные сведения. Содержимое не отображается в интерфейсе и не передаётся третьим лицам.
- Неизвестный формат остаётся доступным как оригинал, но не участвует в интерпретации событий.
- При обрыве скачивания частичный файл не считается сохранённым; повторный автоматический запрос при неясном исходе не выполняется без нового запуска.
- В прямом `index.html` доступен ручной импорт, но не сетевой сбор.

## Requirements

- **FR-001**: JSON по умолчанию включён, логи выключены; пользователь может включить любой один или оба, но не выключить оба.
- **FR-002**: Папка логов выбирается отдельно от папки JSON, не запоминается после сеанса.
- **FR-003**: Сбор осуществляется только для подтверждённой модели и точного IP из плана, без внешних сервисов и временной копии в каталоге проекта.
- **FR-004**: Передача оригинала из runtime в браузер выполняется потоково; логины, cookie, токены и сырые логи не входят в JSON/API-статусы, state и аналитическую таблицу.
- **FR-005**: Ручной импорт читает лишь ограниченный префикс файла для определения формата, сохраняет исходные файлы без изменений и не распаковывает архивы.
- **FR-006**: Метаданные связываются с SR только при единственном точном IP, неоднозначность показывается явно.
- **FR-007**: Функциональность расширяется по модельным контрактам, а неизвестное остаётся `protocol_required`.

## Success Criteria

- **SC-001**: В 100% запусков «только JSON» запросы к логам отсутствуют; в 100% запусков «только логи» файлы опроса JSON не создаются.
- **SC-002**: В 100% синтетических сценариев TE20 оригинал сохраняется в выбранную timestamp-папку либо видна отдельная ошибка, без повреждения JSON-результата.
- **SC-003**: Импорт 1000 файлов использует только ограниченный префикс каждого, не распаковывает архивы и сохраняет отзывчивый интерфейс.
- **SC-004**: Все действующие регрессионные проверки опроса и безопасности проходят.

## Assumptions

- Подтверждены отдельные модельные адреса экспорта для exact Huawei TE20 и TE40. TE30/50/60 используют условный контракт семейства и ожидают эксплуатационной проверки; прочие модели требуют собственного evidence review.
- Первый этап аналитики — метаданные и качество импорта, не интерпретация событий внутри файлов. Это согласовано администратором.
