# Data model

- `collectJson: boolean` (по умолчанию true) и `collectLogs: boolean` (по умолчанию false) в plan schema v3; оба false запрещены. Папки выбираются независимо и не сериализуются в план.
- `PendingLog`: одноразовый ID, безопасное имя `<IP>.xml`, MIME, индекс устройства, поток из устройства; cookie/CSRF и сырые байты недоступны в status JSON.
- `LogImportRow`: относительный путь, имя, размер, тип сигнатуры, время файла/папки, IP из имени, статус единственного сопоставления с актуальной SR, ошибка чтения. Только память вкладки.
- В режиме только логов `polling-recovery.json` хранится в timestamp-папке логов; результат устройства передаётся по ACK как служебный прогресс, но не записывается файлом опроса JSON.
