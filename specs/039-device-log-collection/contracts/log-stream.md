# Contract: log stream

При `collectLogs=true` нужен выбранный и разрешённый browser log root. `collectJson=false` допустим только с `collectLogs=true`: папка JSON не требуется, результат опроса подтверждается без записи файла, а recovery manifest помещается в timestamp-папку логов. Exact TE20 после post-auth model/identity и current bundle marker `exportLogFile` создаёт read-only GET `/log?actkn=<CSRF>?rmd=<nonce>` внутри той же сессии. Один pending log сохраняется только через same-origin `/api/polling/jobs/<id>/log/<logId>`; ответ chunked, без Content-Length и без отражения cookie/token в headers. Браузер потоково пишет `<IP>.xml` в timestamp-папку и ACK-ит результат. При ошибке запись abort, статус безопасный, следующий опрос продолжает работу. Без opt-in либо при другой модели запрос к `/log` запрещён. Импорт не выполняет XML/ZIP содержимое и не распаковывает архив.
