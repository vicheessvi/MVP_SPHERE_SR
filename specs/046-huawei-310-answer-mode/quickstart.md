# Quickstart / acceptance

1. Загрузить текущую SR и выбрать один exact Bar 310 по IP. При «Не менять» убедиться, что план не содержит write action.
2. Выбрать «Вручную», проверить предупреждение об изменении входящих вызовов и отдельное согласие. Без согласия запись не запускается.
3. Разрешённая контрольная запись дала машинный post-read `0` и web-меню «Вручную». После отдельного разрешения возврат дал post-read `1` и web-меню «Автоматически»; исходный режим восстановлен.
4. Повторный запуск той же цели должен дать `already_compliant` без PUT. Неверная модель, конфликт задач и дрейф bundle/schema блокируют запись.
5. Box 310/610 проверять отдельно позже; пока write статус preliminary. Обычный опрос всех моделей остаётся read-only.
6. Запустить Python/JavaScript тесты, проверку Справочника и syntax; проверить отсутствие секретов в JSON/репозитории.
