# Feature Specification: SSH Huawei TE20

**Branch**: `codex/secure-local-runtime`
**Date**: 2026-11-02
**Status**: Implemented; pending live validation

## User Scenarios & Testing

### User Story 1 — Независимый выбор SSH (Priority: P1)

Администратор выбирает один exact TE20 по IP из актуальной SR и устанавливает SSH «Не менять», «Включить» либо «Отключить».

**Independent Test**: Три плана дают соответственно ноль, одно действие включения и одно действие отключения.

**Acceptance Scenarios**:

1. При «Не менять» обычный опрос не отправляет команду изменения SSH.
2. Включение и отключение требуют отдельного подтверждения и одного точного TE20.
3. Чужая модель, массовый режим и сочетание с другой задачей управления блокируются до сети.

### User Story 2 — Подтверждённый результат (Priority: P1)

Администратор видит «уже установлено», «применено» либо безопасную ошибку по SSH.

**Independent Test**: Синтетические ответы проверяют no-op, один write и post-read, неизвестную схему и неверное значение после записи.

**Acceptance Scenarios**:

1. При уже достигнутом целевом значении записи нет.
2. При отличающемся значении отправляется максимум одна запись SSH, успех только после повторного чтения.
3. При ошибке модели, схемы или post-read успех не показывается и неясная запись не повторяется автоматически.

### Edge Cases

- Отключение SSH может прекратить удалённый доступ; это явно указывается перед запуском.
- Действия не переносятся на другие модели без отдельного контракта.
- Состояние пункта меню не доказывает состояние TCP listener.

## Requirements

- **FR-001**: По умолчанию SSH не меняется.
- **FR-002**: Только один exact TE20 из SR может получить отдельную задачу включения либо отключения.
- **FR-003**: Одновременно нельзя выбрать оба действия SSH или совместить их с другими изменениями.
- **FR-004**: После проверки модели и идентичности система должна прочитать бинарное значение, при необходимости записать только SSH один раз и проверить точный результат.
- **FR-005**: Секреты, сырые ответы и данные оборудования не передаются внешним сервисам или в Git.

## Success Criteria

- **SC-001**: Все три варианта формируют ожидаемый план без ложной записи.
- **SC-002**: Во всех синтетических сценариях не более одной записи только выбранного поля и точный post-read перед успехом.
- **SC-003**: Все регрессионные проверки прежних опросов проходят.

## Assumptions

- Задача ограничена Huawei TE20 текущего этапа. Чтение `enable_ssh` подтверждено; команды изменения пока проверены синтетически, но не на живом устройстве.
