# Quickstart / acceptance

1. На отдельном рабочем ПК загрузить актуальную SR, выбрать exact Box 310 по одному IP и запустить обычный JSON-опрос с сеансовыми учётными данными. Задачи изменения настроек не включать.
2. Проверить `vendorPolling.contract`, точную модель, `deviceSettings`, `siteName` и `validationStatus=provisional_user_validation`; значения сверить с меню устройства.
3. Повторить отдельно для exact Box 610. Отчёт одной модели не служит проверкой другой.
4. Проверить неизвестную прошивку/marker/schema: соответствующее поле должно остаться неизвестным, обычные поля опроса — сохраниться.
5. Проверить, что предварительные значения Box не представлены в локальном XLSX как подтверждённые факты и что JSON не содержит секретов.
6. Запустить Python/JavaScript регрессии и проверку Справочника.

Администратор выполнил отдельные опросы Box 310 и Box 610 и подтвердил имена и значения полей. После этого новые JSON содержат `confirmed_user_validation`; старые provisional-файлы по-прежнему должны показывать «Требует проверки».
