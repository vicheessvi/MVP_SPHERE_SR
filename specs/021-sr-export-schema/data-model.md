# Data Model: актуальная схема SR

## Canonical header set

42 уникальных заголовка в порядке XLSX-контракта. Полный перечень закреплён в [contracts/sr-xlsx-v2.md](contracts/sr-xlsx-v2.md).

## Alias registry

- key: внутреннее смысловое имя поля;
- values: канонический заголовок первым и optional legacy aliases после него;
- read rule: вернуть значение первого реально присутствующего заголовка;
- validation rule: обязательное поле считается найденным при наличии любого его допустимого заголовка.

## Location projection

Устойчивый ключ: `SmartRoom ID локации`; fallback сохраняет прежнюю нормализованную комбинацию наименования и адреса. Проекция содержит наименование, адрес, общий и сервисный статусы, описание, комментарий учёта, VIP/избранное, заявки, контакты, подрядчика и гарантию.

## Device projection

Приоритет идентичности: `SmartRoom ID оборудования` → `ID устройства` → inventory → serial+manufacturer → MAC → IP при отсутствии более сильного ключа → fallback. Проекция содержит класс, тип, наименование, статусы, manufacturer/model, IP/MAC, domain, SIP, inventory/serial, питание, интерфейс, IP-протокол и `802.1x`.

## Raw row

Полная исходная строка XLSX сохраняется как deep clone и не переименовывается. Нормализованная проекция не изменяет raw evidence.
