# Validation

1. Синтетическая прежняя БД: подготовка порциями, рестарт посередине, нет повторного чтения XML.
2. 1 000 000 событий: сводка <256 КиБ, страницы <=100, SQL totals совпадают с контрольными числами.
3. Несколько последовательных SR/JSON/log imports: новая история добавляется без потери старой, ошибка staging не публикуется.
4. Переход между модулями и фильтрами во время ожидания; старый ответ игнорируется. Site name не подменяется старым при ошибке последнего опроса.
