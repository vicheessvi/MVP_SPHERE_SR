# ВКС «Учёт»: выключения в нерабочее время

## Specify / clarify

Запрос администратора 2026-11-23: отдельный анализ текущих ВКС со статусом
оборудования «Учёт», без зафиксированных выключений и с ровно одним выключением
за последние два месяца, фильтры, кольца, тепловая карта и скачиваемый XLSX.
Администратор выбрал федеральный календарь РФ, пятидневку с переносами.
После уточнения отдельно подтвердил: суббота, объявленная рабочей производственным
календарём, обрабатывается как рабочий день. Рабочие часы 07:00–18:00,
нерабочие 00:00–07:00 и 18:00–24:00. Изменение расчёта не требуется.

- Начальный период — скользящие два календарных месяца до текущего времени.
  Можно выбрать даты. Время — локальное время терминала, без подмены UTC.
- Выходные/федеральные праздники — весь день. В рабочий день интервал
  [18:00,24:00) и [00:00,07:00). Перенесённая рабочая суббота — рабочий день.
  Региональные праздники и сокращение предпраздничного дня не добавляются:
  администратор явно задал 18:00–07:00.
- Это анализ зарегистрированных событий, не доказательство непрерывной работы.
  «Без записей о выключении» допускается только при наличии валидных событий
  в выбранном периоде. Полнота журнала не предполагается. Устройства без событий,
  Polycom TGZ и неизвестные парсеры относятся к «Недостаточно данных».
- Счётчик выключений — только подтверждённые штатные команды в выбранном
  нерабочем времени. Ровно одно = 1 такая команда. Предположения по паузе отдельны.
  Команда вне выбранного времени не доказывает, что устройство работало ночью.
- Группы не пересекаются: нет штатных/предполагаемых событий; только предположения;
  ровно одно штатное; два и более штатных; недостаточно данных. Перезагрузки
  показываются дополнительно, не заменяют выключения.
- Тепловая карта 7×24 показывает зарегистрированные события выбранной группы,
  не отсутствие записей и не длительность включённого состояния.

## Acceptance / tests before implementation

1. Вне когорты: не-ВКС, иной статус, неактуальная SR, неоднозначные/неподтверждённые
   логи исключены. Знаменатель — текущая отфильтрованная SR, включая неизвестные.
2. Границы 06:59:59/07:00 и 17:59:59/18:00, праздник, воскресенье, рабочая
   суббота, смена года/месяца, неизвестный год; конец периода исключает будущее.
3. Ноль/один/несколько штатных, только пауза, только reboot, отсутствие событий,
   события только в рабочее время. Пауза не прибавляется к штатным.
4. Сумма групп = знаменателю. Применение общих фильтров/группы/карты даёт
   согласованные таблицы и XLSX, безопасный текст, все страницы, stale guard.
5. Полные Python/JS regression и изолированный UI/Excel QA. Никаких реальных
   IP, паролей или журналов в fixtures.
