# Implementation Plan: Раздельная аналитика питания

**Branch**: `codex/secure-local-runtime`
**Date**: 2026-11-12
**Spec**: [spec.md](spec.md)

## Summary

Разделить существующую страницу на две внутренние вкладки; расширить потоковый Bar-парсер кандидатом длительной тишины до boot; объединить безопасные производные события TE/Bar в детерминированную выборку длительности; показать donut с denominator из текущей SR и таблицу выбранного интервала.

## Technical Context

- HTML5, CSS3, Vanilla JavaScript, browser File API; Python runtime и сетевой контракт не меняются.
- Файлы: `runtime/huawei-310-log-events.js`, `runtime/huawei-te-log-events.js`, `app.js`, `styles.css`, `tests.js`, `product-catalog.js`.
- Хранение: только память вкладки; сырые логи не сохраняются.
- Проверки: 199+ JS-регрессий, Python unittest, syntax, reference validation.

## Constitution Check

- Исходные логи неизменны; выводы имеют метаданные файла/строки и версию правила.
- Неоднозначный IP, неизвестная модель и неподтверждённая схема исключаются.
- Пауза — только низкодостоверная гипотеза; подтверждённые выключения отдельны.
- Диаграмма оперирует только производными длительностями и текущей SR, без внешних запросов.
- После дизайна нарушений конституции не обнаружено.

## Design

1. Bar получает `bootGaps` по той же ограниченной схеме, что TE, но не наследует его event markers.
2. UI хранит только активную внутреннюю вкладку и выбранный сегмент диаграммы в памяти.
3. Для каждого устройства берётся максимальная завершённая длительность; подтверждённая — от команды штатного выключения до следующего запуска, предполагаемая — пауза в журнале перед неизвестным запуском. Сырые строки в модель не входят.
4. Период событий фильтрует измерения, но denominator по устройствам задаётся только размерными фильтрами SR; серый сектор показывает отсутствие измерения.
5. Цветная кольцевая диаграмма и кликабельная легенда используют локальные CSS/SVG возможности без изображений, CDN и телеметрии.
6. Тепловая карта — 7×24 кнопки с цветом по уникальным устройствам. Выбор подтверждённых или предполагаемых событий не смешивает группы; ячейка раскрывает сведения SR и ограниченные метаданные источника. Часы берутся из локального времени устройства без конверсии между часовыми поясами.
7. После пользовательского подтверждения аналитики Box 310/610 их модельные события проходят через существующий общий индекс Huawei 310 и автоматически участвуют в диаграмме/карте; отдельный предварительный индекс больше не нужен.
