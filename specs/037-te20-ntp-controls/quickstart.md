# Validation

Запустить Python unit suite, `node tests.js`, reference validator, syntax/compile/diff и private-data scan. Проверить no-change, enable/disable, Auto/Manual, ввод/отсутствие сервера, несовместимые сочетания, неверную модель, marker/schema drift, один write и post-read. Отдельный реальный тест возможен лишь после указания администратором точных значений; в репозиторий не включать реальный адрес и сервер.
