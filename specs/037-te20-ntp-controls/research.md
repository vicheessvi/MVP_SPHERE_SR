# Research

- **Decision**: exact TE20-only contract. **Rationale**: контролируемый read-only опрос подтвердил модель/идентичность и текущие поля NTP; администратор сверил семантику с меню. **Alternative**: перенос на TE30–TE60 без отдельного bundle review — отклонён.
- **Decision**: один action с тремя опциональными полями. **Rationale**: режим и сервер зависят от включения NTP, атомарное намерение проще валидировать и проверить. **Alternative**: три независимых сетевых записи — отклонены из-за риска частичного состояния.
- **Decision**: ограниченная схема текущей прошивки: `synSerTime` и `ntpGetMode` как `CfgItemInt`, `timeServer` как `CfgItemString`, один `WEB_SaveCfgParamAPI`. **Rationale**: код действующего web-bundle прочитан через подтверждённый adapter без записи на устройство; UI ограничивает поле 41 символом.
- **Decision**: при NTP off режим/сервер не менять, при Auto сервер не менять, при Manual требовать сохранённый или введённый сервер. **Rationale**: текущая web-форма отключает зависимые поля и требует сервер для ручного режима.
