# Проверка

1. Запустить инструмент через `START_MVP_SPHERE_SR.py` и открыть закрытый план.
2. Выбрать точный Bar 310, Box 310 либо Box 610; включить «Собирать логи устройств». JSON можно оставить включённым или отключить.
3. Выбрать отдельную локальную папку логов и запустить план. Для самоподписанного сертификата подтвердить исключение только на этот запуск.
4. Проверить файл `<IP>.xml` во вложенной папке времени запуска, его XML-структуру и статус сохранения. Содержимое журнала не пересылать в Git.
5. Для Box 310 и Box 610 сообщить результат отдельно; до этого их статус предварительный.
