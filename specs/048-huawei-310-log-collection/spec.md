# Feature Specification: Сбор логов Huawei 310

**Feature Branch**: `codex/secure-local-runtime`
**Created**: 2026-11-10
**Status**: Implemented — опрос и сбор логов всех трёх точных моделей подтверждены администратором 2026-11-13
**Input**: Добавить автоматический сбор логов Bar 310, Box 310 и Box 610 на основе подключённого Bar 310, сохранив существующие режимы только JSON, только логи и оба варианта.

## User Scenarios & Testing

### User Story 1 — Получить лог Bar 310 (Priority: P1)

Администратор включает «Собирать логи устройств», выбирает отдельную общую папку и запускает опрос точного Bar 310. В папке времени запуска появляется оригинальный лог устройства, а интерфейс показывает результат сохранения без раскрытия содержимого.

**Independent Test**: Один Bar 310 с подтверждённым способом экспорта даёт один файл в выбранной папке; обычный JSON-опрос можно включать или выключать независимо.

**Acceptance Scenarios**:

1. **Given** точный Bar 310 и выбранная папка логов, **When** запущен режим только логов, **Then** оригинал сохраняется локально, JSON-опрос устройства не создаётся, служебный журнал восстановления остаётся видимым.
2. **Given** режим JSON+логи, **When** опрос завершён, **Then** оба результата сохраняются независимо.
3. **Given** ошибка экспорта/сохранения, **When** устройство завершено, **Then** ошибка фиксируется без сырых данных и остальные устройства продолжаются.

### User Story 2 — Расширить на Box 310 и Box 610 (Priority: P1)

Обе точные Box используют тот же общий семейный алгоритм при подтверждённом совпадении признаков их текущего web-интерфейса. Администратор отдельно подтвердил успешный сбор логов на каждой модели 2026-11-13.

**Independent Test**: Синтетические Box 310 и Box 610 проходят только собственные модельные проверки; отсутствие подтверждённого признака экспорта даёт «не поддерживается», без попытки угадывать ресурс.

**Acceptance Scenarios**:

1. **Given** точный Box и совместимый подтверждённый контракт, **When** включён сбор логов, **Then** файл сохраняется со статусом `confirmed_user_validation`.
2. **Given** чужая модель, неподтверждённая схема или несовместимая прошивка, **When** включён сбор логов, **Then** учётные данные не направляются по неизвестному протоколу и ложный файл не создаётся.

### Edge Cases

- Логи могут содержать секреты и инфраструктурные данные; сырое содержимое не входит в JSON устройства, status API, аналитическое состояние или Git.
- Архив и XML не распаковываются и не исполняются при сохранении.
- Повторное сохранение в той же папке не должно перезаписывать чужой файл без проверки.
- Неясный исход или закрытие браузера не должно оставлять скрытую серверную копию лога.
- Сбор логов без JSON остаётся допустимым.

## Requirements

### Functional Requirements

- **FR-001**: Автоматический сбор логов MUST использовать только модельно подтверждённый read-only способ экспорта после проверки exact модели и устойчивой идентичности.
- **FR-002**: Лог MUST потоково записываться только в выбранную пользователем папку запуска; скрытый spool и постоянное хранилище запрещены.
- **FR-003**: Режимы JSON, логи и JSON+логи MUST работать независимо и сохранять существующий механизм продолжения задания.
- **FR-004**: Статус экспорта MUST быть безопасным и не содержать сырой лог, токены, cookie или пароли.
- **FR-005**: Box 310 и Box 610 MUST проходить собственные модельные проверки; их сбор логов подтверждён администратором отдельно и не наследует подтверждение Bar автоматически.
- **FR-006**: Импорт папки логов MUST сохранять существующие метаданные и точное сопоставление IP; подтверждение сбора не означает подтверждения событийной аналитики Box 310/610.

### Key Entities

- **LogArtifact**: оригинальный файл, точная модель/IP, имя и тип файла, время загрузки, статус сохранения.
- **LogCollectionResult**: безопасный статус и модельная степень проверки без содержимого.

## Success Criteria

- **SC-001**: При подтверждённом Bar-экспорте лог сохраняется в выбранной папке и открывается локально без вмешательства сервера.
- **SC-002**: 100% неподтверждённых модельных/схемных случаев не создают ложных файлов или внешней передачи.
- **SC-003**: Синтетические тесты подтверждают все три режима вывода, отказ одного устройства и отсутствие секрета в результатах.
- **SC-004**: Администратор независимо подтвердил опрос и сбор логов Bar 310, Box 310 и Box 610.

## Assumptions

- Первый этап сохраняет оригиналы логов и метаданные; анализ событий внутри формата — отдельная задача после образцов.
- На Box модельный путь экспорта может отличаться; без совпадения фактического контракта будет явный `protocol_required`.
