# Контракт read-only интервала сна Bar 300

Актуализация ADR-0054: общий узкий reader доступен exact Box 300/600 после собственных model/identity gates и bundle-маркеров. Администратор сверил их значения с меню; новые Box-факты имеют `confirmed_user_validation`, старые provisional JSON не переписываются. Живые коды ниже исследованы агентом только на Bar 300; это уточнение заменяет прежнюю фразу о запрете наследования.

Только exact Bar 300 после numeric pre-auth model и post-auth model/identity gates. Текущий bundle должен содержать форму `SelSleepDuration` с `sleepTime` и `powerMagParams` с тем же ID; видимые коды `{0,1,5,10,15,30,60}` соответствуют «Никогда» и минутам. Узкий `WEB_GetCfgParamAPI` запрашивает только `CfgIDString=["sleepTime"]` с текущим CSRF; широкую базовую группу, включающую `api_user`, `admin_user` и email, не запрашивать.

Строгое целое из набора кодов → `deviceSettings.fields.powerManagement.status=read`, `value.sleepTimeCode`, `value.sleepMode=never` только при 0, иначе `interval`; `source=WEB_GetCfgParamAPI:sleepTime`. Сохранённый код 10 подтверждён обычным живым опросом и администратором как 10 минут. Отсутствующий маркер → `protocol_required`, ошибка/другой код → `unavailable`. Box 300/600 не наследуют чтение. Команд изменения питания нет.

Если текущий bundle дополнительно содержит radio `RGNetworkWakeUp` с кодами `enable_wol` 1/0, после подтверждённого сна отдельный узкий запрос читает только `CfgIDString=["enable_wol"]`. Строгое 0/1 добавляет `value.networkWakeEnabled` и расширяет источник до `WEB_GetCfgParamAPI:sleepTime,enable_wol`; ошибку/неизвестный код не подменять ложным значением, а оставлять `networkWake` в `unconfirmedFields`. На подключённом Bar 300 0 совпал с меню «Запрещать»; ветка 1 пока подтверждена только web-формой. Остальные поля питания остаются в `unconfirmedFields`.

По тем же правилам отдельно и последовательно читаются только `faceWakeUp`, `sleepCloseAPP`, `autoReboot` при собственных radio-маркерах формы 1/0. Ответ 0/1 добавляет соответственно `faceWakeEnabled`, `clearMemoryInSleepEnabled`, `automaticRestartEnabled`; источник расширяется только фактически прочитанными ID, ошибка отдельного запроса сохраняет другие подтверждённые поля. На Bar 300 все три кода 0 совпали с меню и вошли в контрольный JSON. Ветки 1 пока лишь по форме. При `autoReboot=1` не выдавать ложный период: `automaticRestartIntervalDays` остаётся в `unconfirmedFields` до отдельного чтения `autoRebootVal`; при `autoReboot=0` период неактивен. Скрытый `suppotReboot` не читать и не выводить как состояние видимого автоперезапуска.
