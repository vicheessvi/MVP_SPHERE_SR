# Контракт read-only Wi‑Fi Bar 300

Актуализация ADR-0054: тот же статусный reader предварительно доступен exact Box 300/600 только после их собственных model/identity gates и текущих bundle-маркеров. Подтверждённые циклы ниже относятся лишь к Bar 300; новые Box-факты имеют `provisional_user_validation`. Это заменяет прежнюю фразу о запрете наследования.

Только exact Bar 300 после существующих pre-auth numeric model и post-auth model/identity gates. Текущий bundle должен содержать `WEB_GetWifiStatModeAPI`, его read-only вызов, форму `RGEnableSta`/`RGEnableAp` и отображение `getCurrentWifiMode`. POST выполняется с текущим `acCSRFToken`; тело не содержит SSID или пароль. Из ответа принимается только строгое целое `ucWifiMode` в `{0,1,2,3}`. Значение 0 означает клиент и точка доступа выключены; 2 — только клиент, подтверждено ручным циклом `0→2→0`; 1 — только точка доступа, подтверждено отдельным циклом `0→1→0` с повторным чтением после возврата. Код 3 означает оба включены по текущему bundle, эксплуатационная проверка ещё не выполнена. Источник факта: `WEB_GetWifiStatModeAPI:ucWifiMode`.

Не вызывать `WEB_GetWifiCfgAPI` из-за возможных SSID/пароля. Другие поля статусного ответа, включая MAC, не включать в JSON. Отсутствие bundle-маркера → `protocol_required`, неизвестный код или ошибка ответа → `unavailable`. Box 300/600 не наследуют контракт. Команд изменения нет.
