# Контракт read-only NTP Bar 300

Актуализация ADR-0054: тот же reader доступен exact Box 300/600 только после собственных model/identity gates и маркеров их текущего bundle; администратор сверил значения обеих Box с меню, новые факты имеют `confirmed_user_validation`. Исторические provisional JSON не переписываются, циклы ниже относятся лишь к Bar 300.

Только exact Bar 300 после pre/post-auth model и identity gates. Текущий bundle должен содержать config-группу с `synSerTime`, `ntpGetMode`, `timeServer` и формы с кодами `synSerTime 1=включено/0=выключено`, `ntpGetMode 0=Авто/1=Вручную`. Узкий `WEB_GetCfgParamAPI` запрашивает только эти три ID с текущим CSRF. Строгие целые 0/1 и строка сервера не длиннее 255 символов без управляющих символов; включённый ручной режим требует непустую строку. Неизвестная схема → `protocol_required`, некорректный ответ → `unavailable`. Пригодный ответ добавляет в JSON `enabled`, `modeCode`, `mode`, `server` с источником `WEB_GetCfgParamAPI:synSerTime,ntpGetMode,timeServer`. Адрес остаётся только в локальном результате; режим сервера подтверждён ручным циклом `1=Вручную → 0=Авто → 1=Вручную`, синхронизация — циклом `1=Включена → 0=Выключена → 1=Включена`. Администратор проверил, что исходный ручной сервер сохранён; качество связи с ним не утверждается.
