# Data Model

- `BulkAnswerSelection`: режим `filters|single_ip`, точные устройства актуальной SR и один модельный action ID.
- `BulkWriteConfirmation`: число целей и целевой режим ответа, подтверждённые администратором перед запуском.
- `DeviceResult`: отдельный результат per-device pre/read/write/post-read, без объединённого статуса успеха для всего набора.
- Неизвестные/несовместимые цели не входят в запущенный write-план; весь план отклоняется до передачи учётных данных.
