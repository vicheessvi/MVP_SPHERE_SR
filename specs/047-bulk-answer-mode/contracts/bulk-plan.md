# Contract: bulk Answer mode plan

Для action ID одной из групп TE20, TE30/40/50/60 или Huawei 310 `targetSource=sr`, `targetSourceSha256` — валидный digest актуальной SR, `selection.mode=filters|single_ip`, `devices` — непустой список точных уникальных IP. Все устройства обязаны поддерживать выбранный action по каталогу. Другие write-action, вторая противоположная задача, портовый список и смешанная модельная группа запрещены. UI показывает число целей и отдельно подтверждает изменение входящих вызовов.

Runtime проверяет те же условия независимо от браузера. Обработка устройств последовательна; модельный адаптер сохраняет прежние pre/post-read и максимум одну запись. Неясный write не повторяется автоматически; результаты остальных устройств сохраняются.
