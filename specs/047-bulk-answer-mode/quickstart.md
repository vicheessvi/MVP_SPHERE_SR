# Quickstart / acceptance

1. Загрузить текущую SR; выбрать по фильтрам только TE20, только TE30/40/50/60 либо только Bar 310/Box 310/Box 610.
2. Выбрать целевой Answer mode и убедиться, что показано количество выбранных устройств и предупреждение о массовом изменении.
3. Проверить, что смешанная группа, неподдерживаемая модель и совмещение с HTTP/другими задачами блокируются до запуска.
4. Проверить существующий выбор одного IP и «Не менять» без write.
5. Синтетически выполнить два устройства: отдельные результаты, один отказ не повторяется и не отменяет другое; интервалы сохраняются.
6. Запустить Python/JavaScript регрессии, справочник и syntax. Реальный массовый write без отдельного согласия не выполнять.

Администратор позднее подтвердил оба направления на всех восьми точных моделях как для одного IP, так и для массового выбора. При новых проверках всё равно требуется явное согласие перед каждым write-планом.
