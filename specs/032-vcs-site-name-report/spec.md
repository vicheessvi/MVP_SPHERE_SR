# Таблица Site name терминалов ВКС — SpecKit-lite

## Цель

В категории «Оборудование → Терминалы ВКС» показывать и локально скачивать актуальное значение Site name рядом с инвентарными сведениями из SR.

## Входит в задачу

- Переключатель «Устройства / Site name» в существующем разделе без нового маршрута.
- Те же действующие фильтры для обеих таблиц.
- Столбцы в одном порядке на экране и в XLSX: «Наименование устройства», «Site name», «IP», «MAC», «Адрес», «Наименование локации», «Домен».
- Site name только из самого нового привязанного результата устройства, если опрос успешен и значение подтверждено. При отсутствии поля или ошибке нового результата значение пустое; старое имя не подставляется.
- XLSX формируется в памяти браузера и скачивается по кнопке «Скачать Site name», без сетевой передачи.

## Не входит

- Новый опрос устройства или изменение его настроек.
- Изменение исходных SR и JSON, постоянное хранение таблицы, серверный экспорт или новый модуль меню.
- Подстановка имени локации SR вместо Site name.

## Критерии приёмки

1. В разделе Терминалов ВКС выбор Site name мгновенно показывает таблицу с семью указанными заголовками; все существующие фильтры продолжают действовать.
2. Для двух результатов одного устройства отображается значение только из более нового. Если новый результат неуспешен или не содержит подтверждённый Site name, поле остаётся пустым.
3. Кнопка создаёт однотабличный XLSX с теми же строками и порядком столбцов, что видны по текущим фильтрам. IP и MAC остаются текстом; строка, похожая на формулу, не становится формулой.
4. Экспорт доступен при прямом запуске `index.html` и в локальном Python-режиме, без CDN и внешних запросов.
5. Пустой набор фильтра не даёт вводящего в заблуждение файла; секреты не попадают в таблицу.

## Риски и решения

- `capturedAt` результата использует установленное приложением время файла и существующий порядок сортировки. Новый экран не вводит отдельную хронологию.
- Незаполненный Site name показывается как «—» на экране и пустая текстовая ячейка в XLSX.
- Значения имени и адресов могут быть похожи на формулы; при экспорте все семь полей записываются только как строки.
- Большой перечень обрабатывается одним индексом последнего результата по устройству, без повторного разбора сырых JSON при каждом рендере.
