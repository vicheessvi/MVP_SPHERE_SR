# UI contract

- Маршрут `reboots`: обзор из интерактивных карточек. Кнопка с `data-reboot-view` открывает один блок с таблицей или графиком; закрытие возвращает обзор. Все строки используют `getRebootAnalytics` с текущими фильтрами.
- Маршрут `project-versions`: таблица истории `Project Info.Version` по устройству и времени.
- Маршрут `firmware-versions`: таблица истории `Firmware.Version` по устройству и времени.
- Маршрут `connection-errors`: две отдельные таблицы подтверждённых статусов.
- Маршрут `poll-sr-comparison` остаётся «В разработке».
- Никакая UI-таблица не содержит raw JSON или секреты.
