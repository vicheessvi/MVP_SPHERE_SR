# Research

- **Decision**: События перезагрузок группируются по `deviceId`/`locationId`. **Rationale**: отображаемые имена могут совпадать. **Alternative**: строковая группировка имён отвергнута из-за смешения устройств.
- **Decision**: Для проектов читается `webBlocks.Project Info.Version`, для прошивок — `webBlocks.Firmware.Version` (без учёта регистра ключа). **Rationale**: это уже создаваемые текущими адаптерами поля. **Alternative**: угадывание версий по произвольному `version` отвергнуто.
- **Decision**: Только `matchStatus=matched`, `parseStatus=parsed`, `pollStatus=success` участвуют в истории версий. **Rationale**: не смешивать ошибки чтения и версии другого устройства.
- **Decision**: Ошибки берутся из уже нормализованного `pollStatus`, который отдельно подтверждает отказ авторизации и сетевую недоступность. **Rationale**: не перечитывать сырые строки ошибок догадками.
- **Decision**: Один активный раскрытый блок внутри маршрута перезагрузок; применённые фильтры общие для всех таблиц. **Rationale**: обзор остаётся компактным.
