# Quickstart: проверка автоматического опроса внутри инструмента

1. Запустить `powershell.exe -ExecutionPolicy Bypass -File .\start.ps1` и убедиться, что браузер открыл URL `127.0.0.1`.
2. Загрузить синтетическую SR и XLSX `Логин | Пароль`; выбрать общую папку результатов.
3. Сформировать план, явно включить режим самоподписанного сертификата и нажать «Запустить опрос».
4. На подменённом polling adapter проверить: создаётся одна папка `YYYY-MM-DD_HH-mm-ss`, первый JSON записан до интервала, второй появляется после интервала.
5. Отменить отдельный запуск во время ожидания: следующий запрос отсутствует, сохранённый JSON остаётся.
6. Открыть `index.html` напрямую: ручной импорт работает, автоматический запуск заблокирован с инструкцией `start.ps1`.
7. Импортировать созданную общую папку через ручной раздел и проверить сопоставление результатов по точному IP.
8. Запустить `node tests.js`, `node runtime-tests.js`, `node server-tests.js`, `node scripts/validate-reference.js`, syntax, diff и secret scans.
