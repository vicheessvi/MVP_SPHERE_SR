# Контракт локальной рабочей базы

> Исторический контракт feature 058. Feature 060 / ADR-0063 заменяет монолит и общий потолок порционным API и добавляет файловые checkpoints. Ограничения ниже относятся только к совместимому старому клиенту, не к текущему сохранению.

Все `/api/workspace/*` работают только через существующий loopback Host/session, после admin unlock; изменения требуют `Origin` и `X-MVP-CSRF`. Ответы/ошибки не содержат исходных payload, учётных данных или SQL-текста.

- `GET /api/workspace/status`: выбранная папка, версия схемы, ревизия, число файлов/событий, состояние целостности; если папка отсутствует — безопасный `not_configured`, если недоступна/повреждена — явная ошибка без новой базы.
- `POST /api/workspace/select`: явный выбор локальной абсолютной папки. Не разрешать корень диска, профиль пользователя целиком, каталог репозитория/`.git` и системные папки; сохранять указатель пути атомарно вне Git. Базу создать только после подтверждённого выбора.
- `POST /api/workspace/choose`: открывает native folder chooser только после административного входа; при отсутствии GUI остаётся ручной ввод пути.
- `GET /api/workspace/snapshot`: последняя завершённая safe projection и компактные аналитические индексы с ревизией. Ответ ограничен максимальным размером снапшота 128 МиБ; при превышении сохранение отклоняется без замены предыдущей ревизии.
- `POST /api/workspace/commit`: `baseRevision`, версия проекции, безопасное состояние SR/JSON, metadata registry и compact event indexes. Проверить схему, размер, отсутствие rawText/секретных ключей и inline токенов; SQLite `BEGIN IMMEDIATE`/commit и ревизия+1. При несовпадении ревизии — 409 без записи; при неполном запросе — прежняя ревизия без изменений.

Незавершённый первый импорт не checkpointed по каждому файлу: последняя завершённая ревизия сохранена, текущую попытку после сбоя потребуется повторить. Данные базы не отправляются внешним сервисам, не дублируются в browser storage и не помещаются в Git. Прямой `file://` не вызывает эти маршруты.
