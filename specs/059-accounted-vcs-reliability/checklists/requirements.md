# Проверка требований: ВКС в учёте

- [x] Подтверждены новая и старая подписи поля SR и точная принадлежность статуса оборудованию.
- [x] Разделены перезагрузка, штатное выключение и низкодостоверная пауза.
- [x] Определены знаменатель, уникальные устройства, события и реакция фильтров.
- [x] Предусмотрены кликабельные детализации, топы и два отдельных XLSX.
- [x] Неизвестные Polycom/другие форматы не превращаются в ноль событий.
- [x] Указаны масштаб, недостоверность, формульная защита и локальный экспорт.
