# Проверка среза ВКС «Учёт»

1. Загрузить синтетическую актуальную SR с оборудованием «Учёт», «Норма», «Внимание», включая старый и новый заголовки статуса. Проверить denominator только VCS «Учёт».
2. Импортировать повторные Huawei XML с reboot, web/remote power-off и паузой. Проверить уникальные устройства против числа событий, отдельную достоверность и отсутствие двойного счёта повторных файлов.
3. Изменить домен/VIP/модель/период; проверить оба кольца, топы, карту и клик по ячейке. Polycom TGZ остаётся «нет событийного анализа».
4. Скачать два XLSX; открыть и сверить количество/первые/последние времена, текстовые формульные строки, auto-filter и отсутствие реальных секретов.
5. Запустить `node tests.js`, `node scripts/validate-reference.js`, `node --check app.js`, полный Python suite и `git diff --check`. Реальную рабочую SR/логи пользователь проверит после получения ветки.
