# Data Model: ВКС «Учёт»

## AccountedDevice

Текущее `inventoryDevices` с `category=vcs`, `inCurrentSr!==false`, `equipmentOverallStatus=Учёт`, id и текущими моделью, производителем, IP/MAC, доменом, VIP, локацией/адресом. Только это множество образует 100% каждой диаграммы после фильтров.

## AccountedEvent

Ранее извлечённое логом событие: `deviceId`, `kind=confirmed_reboot|power_off|suspected_power_loss`, локальное время, ruleVersion, confidence и ссылки на файл/строку. Устройство без событийного контракта остаётся в cohort как «нет данных», не как доказанная нулевая частота.

## DeviceSummary

По одному устройству: отдельные количества трёх видов, первая/последняя дата каждого, метаданные SR, число источников. Порядок топа: число событий по выбранному виду убывает, затем имя, затем id. Списки Excel используют те же строки без экранного лимита.

## Selection

Общие фильтры периода, домена, производителя, модели, локации, адреса, VIP и порога тишины. Интерактивный `view=all|reboot|power_confirmed|power_suspected|none` плюс ячейка `day:hour`; смена фильтра сбрасывает несовместимый drill-down.
