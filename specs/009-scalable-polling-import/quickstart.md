# Quickstart: Проверка масштабируемого импорта

1. Откройте `index.html` двойным щелчком и перейдите в «Загрузка».
2. Выберите общую папку, содержащую dated-папки `YYYY-MM-DD_HH-MM-SS` с JSON.
3. Проверьте этап, обработано/всего, успехи, ошибки, дубликаты, скорость и ETA.
4. Для проверки отмены нажмите «Отменить загрузку»: должны сохраниться уже обработанные результаты и появиться «Загрузка остановлена пользователем.»
5. Выберите тот же набор повторно: результаты и изменения не должны удвоиться.
