# Feature Specification: Автоматический опрос Huawei TE40

**Feature Branch**: `codex/secure-local-runtime`

**Created**: 2026-09-03

**Status**: Draft

**Input**: User description: "Добавить в инструмент отдельный алгоритм автоматического опроса терминалов ВКС Huawei TE40 через штатный веб-интерфейс, используя загружаемые из Excel стандартные учётные данные для производителя и модели. Сохранить ручную загрузку опросов и локальную защиту данных."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Автоматический опрос TE40 (Priority: P1)

Администратор МЦТП формирует план по выгрузке SR, загружает файл стандартных учётных данных и запускает опрос Huawei TE40. Инструмент авторизуется через подтверждённый штатный веб-интерфейс и получает идентификационные и эксплуатационные параметры устройства.

**Why this priority**: Это основной пользовательский результат — терминал Huawei должен опрашиваться тем же массовым workflow, что и уже поддерживаемые устройства, без ручного входа в веб-интерфейс.

**Independent Test**: Синтетический совместимый терминал принимает подтверждённую последовательность входа и возвращает MAC, серийный номер, сведения о версии, модели, времени и сети; результат выдаётся как один безопасный файл опроса.

**Acceptance Scenarios**:

1. **Given** в плане есть поддерживаемый Huawei TE40 и загружена подходящая пара, **When** администратор запускает опрос с разрешённым локальным TLS-исключением, **Then** устройство успешно авторизуется и возвращает подтверждённые read-only параметры.
2. **Given** в файле несколько стандартных пар, **When** первая пара отклонена, **Then** инструмент последовательно проверяет следующие пары в пределах существующего лимита и не раскрывает значения ни одной пары.
3. **Given** опрос успешен, **When** результат передаётся на запись, **Then** он совместим с общей папкой ручных и автоматических опросов и не содержит cookie, CSRF-токенов, логинов или паролей.

---

### User Story 2 - Безопасный отказ (Priority: P2)

Администратор получает понятный безопасный статус, если терминал недоступен, учётные данные отклонены, TLS-контракт не поддерживается или схема ответа отличается от подтверждённой.

**Why this priority**: Неизвестный ответ устройства нельзя принимать за достоверный снимок или превращать в утечку диагностических данных.

**Independent Test**: Для каждой ошибки инструмент возвращает стабильный код этапа без исходного тела ответа, секретов и частичных чувствительных значений.

**Acceptance Scenarios**:

1. **Given** все пары отклонены, **When** завершается авторизация, **Then** результат сообщает об ошибке авторизации без логинов, паролей и тел ответов.
2. **Given** веб-интерфейс не содержит подтверждённых признаков TE40, **When** запускается опрос, **Then** инструмент завершает его как неподдерживаемый контракт и не угадывает другие endpoint.
3. **Given** ответ превышает лимит или истекает timeout, **When** завершается запрос, **Then** инструмент останавливает этот опрос и возвращает безопасный ограниченный статус.

---

### User Story 3 - Сосуществование с другими алгоритмами (Priority: P3)

Администратор может включать Huawei TE40 и устройства других производителей в один план; каждое устройство направляется только в свой подтверждённый алгоритм, а ручная загрузка файлов продолжает работать без изменений.

**Why this priority**: Инструмент должен накапливать независимые алгоритмы без смешивания протоколов и регрессии существующего Extron workflow.

**Independent Test**: Смешанный синтетический план направляет Huawei и Extron в разные алгоритмы, сохраняет последовательность результатов и не меняет ручной импорт.

**Acceptance Scenarios**:

1. **Given** смешанный план Huawei и Extron, **When** запускается опрос, **Then** для каждого устройства применяется только алгоритм его производителя и категории.
2. **Given** пользователь открывает HTML напрямую, **When** он загружает готовую общую папку вручную, **Then** сетевой опрос остаётся недоступным, а аналитика принимает сохранённые Huawei JSON.

### Edge Cases

- Устройство отвечает по HTTP, но требует перехода на HTTPS.
- Сертификат локального устройства не доверен Windows, а разрешение небезопасного TLS не дано пользователем.
- Устройство поддерживает TLS, несовместимый с современными настройками по умолчанию.
- Веб-интерфейс сообщает об уже активной сессии.
- Авторизация успешна, но обязательный идентификационный endpoint отсутствует или меняет схему.
- Один из необязательных read-only endpoint недоступен при корректных остальных ответах.
- В файле учётных данных отсутствует подходящая пара либо все пары отклонены.
- Опрос отменён между запросами или до подтверждения записи результата.

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: Инструмент MUST распознавать Huawei TE40 из действующего каталога и направлять его только в подтверждённый алгоритм Huawei TE40.
- **FR-002**: Алгоритм MUST использовать только явно указанный IP из неизменяемого плана и не выполнять поиск соседних адресов.
- **FR-003**: Алгоритм MUST воспроизводить подтверждённую последовательность штатного веб-входа, включая предварительную инициализацию, сеансовую cookie и противодействующий подделке токен.
- **FR-004**: Недоверенный сертификат MAY приниматься только для явно выбранного локального устройства и только при включённом пользователем разрешении небезопасного TLS.
- **FR-005**: Алгоритм MUST использовать только подтверждённые read-only операции веб-интерфейса и MUST NOT выполнять изменение конфигурации, перезагрузку, обновление или выход из чужой сессии.
- **FR-006**: Первая поддерживаемая версия MUST извлекать доступные подтверждённые идентификационные данные, включая системный MAC и серийный номер, а также сведения о версии, модели/характеристиках, локальном времени и сетевой конфигурации.
- **FR-007**: Для признания снимка успешным MUST присутствовать минимум один устойчивый идентификатор устройства и подтверждённые признаки ожидаемого веб-контракта.
- **FR-008**: Необязательный недоступный параметр MUST отражаться как неизвестный с безопасной диагностикой и MUST NOT отменять корректные подтверждённые поля.
- **FR-009**: Логины, пароли, cookie и сеансовые токены MUST существовать только в памяти активного опроса и MUST NOT попадать в state, DOM, план, JSON результата, аналитику, логи, backup или Git.
- **FR-010**: Каждый запрос MUST иметь ограничение времени и объёма ответа; неизвестный контракт MUST завершаться закрытым безопасным отказом.
- **FR-011**: Результат MUST использовать общий формат автоматических опросов и сохраняться только в выбранную пользователем папку после действующего ACK-механизма.
- **FR-012**: Существующие алгоритм Extron, смешанные планы и ручная пакетная загрузка MUST сохранять текущее поведение.
- **FR-013**: Пользовательские статусы и Справочник MUST явно сообщать о поддержке Huawei TE40 и условиях локального HTTPS-опроса без публикации внутренних данных.

### Key Entities

- **Цель Huawei TE40**: Устройство из плана с точным IP, категорией, производителем, моделью и пользовательским TLS-разрешением.
- **Сеанс опроса Huawei**: Краткоживущий контекст авторизации с cookie и токеном, существующий только в памяти одного устройства.
- **Подтверждённый параметр**: Значение из известной read-only операции с зафиксированным источником и ожидаемой схемой.
- **Результат опроса**: Ограниченный JSON со временем сбора, подтверждёнными параметрами, безопасными статусами полноты и без секретов.

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: Совместимый Huawei TE40 с действующей парой выдаёт результат с системным MAC и минимум двумя дополнительными подтверждёнными группами параметров за один запуск.
- **SC-002**: 100% синтетических сценариев успеха, ошибки авторизации, неизвестного контракта, timeout/TLS и удаления секретов завершаются ожидаемым безопасным статусом.
- **SC-003**: Проверка результатов и диагностик на набор маркеров секретов не обнаруживает логинов, паролей, cookie или токенов ни в одном terminal path.
- **SC-004**: Смешанный план из Huawei TE40 и Extron выполняется последовательно, выдаёт по одному результату на цель и не смешивает данные или алгоритмы между IP.
- **SC-005**: Все существующие проверки ручного импорта, аналитики и Extron polling проходят без регрессии.

## Assumptions

- Первый подтверждённый объём относится к семейству веб-интерфейса, воспроизводимо проверенному на Huawei TE40; другие модели Huawei остаются `protocol_required` до отдельного evidence review.
- Учётные данные стандартны для производителя/модели и поступают через существующий XLSX-пул; привязка реальных секретов к репозиторию не требуется.
- Автоматический опрос выполняется только через полный локальный runtime; прямой запуск HTML сохраняет ручной режим.
- Недоверенный локальный сертификат ожидаем для этого поколения устройств, но его принятие остаётся явным выбором пользователя для каждой цели/плана.
- MAC, серийный номер, IP и прочие результаты являются чувствительными инфраструктурными данными и не используются в тестовых fixtures в реальном виде.
