# Recheck contract

API /api/workspace/* сохраняет session/admin/Origin/CSRF. Нового сетевого API
кодеков нет. Новый ruleset не использует старые registry/checkpoints как готовые.
Полная выборка источников, неизменная SR, private staging, per-file checkpoints,
atomic finish. Неполный XML/ошибка разбора прежнего файла запрещают публикацию.
Отмена/рестарт не очищают опубликованную аналитику; повторный выбор папки
восстанавливает результаты уже успешно разобранных файлов текущей версии.

Старая БД не содержит сырого журнала: автоматическое восстановление новых событий
без повторного выбора исходных файлов запрещено. На версии правила не меняется
polling plan, разрешение TLS или команды записи.
