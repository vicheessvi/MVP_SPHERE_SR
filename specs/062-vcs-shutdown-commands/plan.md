# Plan

Python 3.11 stdlib, Vanilla JS, SQLite как в feature 061. Новый общий UMD helper
классифицирует только сообщение об отключении терминала. Три Huawei scanner
сохраняют собственные форматы/времена/модельные gates и вызывают общий helper.
Legacy Terminal powered off сохраняется. Web/remote — канал записи, не источник
доказанного пользователя. Инициатор по умолчанию не установлен, не извлекается
из имени пользователя или похожего IP.

Обновляются собственные ruleVersion моделей, registry получает analysisRuleVersion,
scope/key checkpoint включает ruleset. Старый checkpoint schema остаётся читаемым,
но прежний namespace не используется новым кодом. Полная перепроверка требует
всех прежних источников и использует logs-replace staging + atomic finish;
DB-first не восстанавливает историю в браузер. Перепроверка повторно использует
готовые новые scans. Нужен полный проход оригиналов, БД хранит не исходные строки.

PASS: пользователь явно утвердил расширение семантического правила. Сохраняются
identity/SR/формат, provenance, раздельные типы, защищённый workspace API, отсутствие
сырого текста/секретов и внешней передачи. У poll/write contracts изменений нет.

Неизвестные архивы не распаковываются/не активируются без контракта.
