# Спецификации фич

Эта папка хранит спецификации фич.

## Рекомендуемая структура

`specs/NNN-short-feature-name/`

Для Full SpecKit-задач использовать:
- `spec.md` — продуктовое поведение, пользовательская ценность, требования, acceptance criteria
- `plan.md` — технический подход
- `tasks.md` — маленькие исполнимые задачи

## Правила

- Когда использовать Full SpecKit / SpecKit-lite / Короткий prompt — см. `../docs/development-workflow.md` (единственный источник правды для этого правила).
- Не создавать огромные спецификации для мелких правок.
- Не описывать реализацию слишком рано в `spec.md`.
- Не фиксировать предположения как факты.
- Использовать `TBD` или `Открытые вопросы`, если нужна ясность.
