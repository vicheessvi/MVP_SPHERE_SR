# Проверка сбора логов CloudLink 300

1. На рабочем ПК запустить `START_MVP_SPHERE_SR.py`, войти как Администратор МЦТП и загрузить актуальную SR. Прямой `index.html` не выполняет сетевой опрос.
2. В «Загрузка данных и опрос устройств» выбрать папку логов, модель exact Bar 300 и опцию «Собирать логи устройств»; при необходимости выключить JSON, чтобы проверить режим только логов.
3. Для самоподписанного сертификата дать разрешение только текущему запуску. Проверить, что в timestamp-папке появился один `<IP>.xml`, а статус `logCollection` стал `saved` только после сохранения.
4. Отдельно проверить совместный режим JSON+логи и ошибку сохранения: другие устройства должны продолжиться, сырой лог/секреты не должны оказаться в status JSON.
5. Импортировать папку логов существующей кнопкой и проверить метаданные/точное сопоставление IP. Не утверждать событийную аналитику по этой feature.
6. Для Box 300 и Box 600 повторить проверки по каждой модели. Пока администратор не сверит реальные файлы, их новые результаты имеют `provisional_user_validation`; отсутствие bundle-маркеров даёт `protocol_required`.
