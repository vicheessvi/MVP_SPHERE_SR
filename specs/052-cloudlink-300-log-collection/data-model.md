# Data model: журнал CloudLink 300

## LogCollectionResult

- `status`: `saved`, `failed` либо `protocol_required`.
- `safeError`: только машинно безопасный код при отказе, без ответа устройства.
- `validationStatus`: `provisional_user_validation` для всех трёх моделей до подтверждения полноценного сохранения и импорта оригинала администратором; проверка префикса Bar 300 не равна полной эксплуатационной проверке.
- Не содержит cookie, CSRF, пароля, сырого XML и строк журнала.

## LogArtifact

- Один потоковый оригинал `<IP>.xml` в выбранной пользователем timestamp-папке логов.
- Метаданные текущего импорта: имя, IP из имени и сопоставление с актуальной SR, время файла, тип и ошибка чтения.
- Runtime не держит постоянную копию. Browser подтверждает запись через существующий ACK; при отказе запись прерывается и статус отдельного устройства фиксируется.

## State transitions

`not_started → pending_stream → saved|failed`; если схема экспорта не подтверждена, `protocol_required` без создания stream. Переход `saved` допустим только после ACK локального сохранения. При `collectJson=false` JSON устройства не пишется, но существующий recovery manifest остаётся в папке логов.
