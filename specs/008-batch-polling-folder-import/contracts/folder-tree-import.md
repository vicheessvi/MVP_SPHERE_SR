# UI Contract: Импорт дерева папок опросов

## Input

- Пользователь выбирает ровно одну общую папку через directory picker.
- Относительный путь браузера имеет форму `ROOT/.../RUN_FOLDER/.../FILE.json`.
- `RUN_FOLDER ::= YYYY-MM-DD_HH-MM-SS` с проверкой реальной календарной даты.
- Расширение `.json` сравнивается без учёта регистра.

## Grouping

- Сеанс задаёт ближайший к файлу валидный `RUN_FOLDER`.
- Ключ группы — нормализованный относительный путь этой папки.
- Группы сортируются по времени, при равенстве — по пути.
- JSON без валидного предка не передаётся в аналитику.

## Output

- Общий итог: найдено папок, обработано JSON, ошибок, проигнорировано не-JSON.
- Групповой итог: путь папки, число файлов и статус `processed`, `partial` или `failed`.
- Ошибка файла: относительный путь и безопасная причина без публикации содержимого.

## Safety

- Читаются только файлы, явно переданные File API после действия пользователя.
- Внешние запросы не выполняются.
- Содержимое и пути не сохраняются в браузерное постоянное хранилище.
