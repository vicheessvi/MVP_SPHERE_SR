# Launch Contract: Единственный файловый режим

## Supported

- Протокол страницы: `file:`.
- Маркер: `runtime-config.js` установил `__MVP_FILE_RUNTIME__`.
- Хранилище: только `createVolatileStorage()`.
- Точка входа: корневой `index.html`.

## Unsupported

- HTTP/HTTPS не объявляется отдельным рабочим режимом.
- Серверный secure marker не меняет контракт запуска интерфейса.
- Импорт учётных данных и сетевой опрос из браузерной страницы не выполняются.

## Observable Result

- При `file:` приложение открывает все доступные модули.
- При другом протоколе показывается инструкция открыть корневой `index.html`.
