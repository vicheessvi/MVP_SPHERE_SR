# Data Model: Пакетный импорт папок опросов

## SelectedFolderTree

- `files`: явно выбранные браузером локальные файлы.
- `selectedRootName`: первый сегмент относительных путей, информационное поле.
- Не сохраняется после завершения чтения; дескрипторы файлов существуют только в памяти.

## PollingRunBatch

- `folderName`: сегмент `YYYY-MM-DD_HH-MM-SS`.
- `folderPath`: нормализованный относительный путь папки от выбранного корня.
- `capturedAt`: валидированное локальное время папки в ISO-представлении.
- `files`: JSON-дескрипторы, отнесённые к этой папке.
- `identityKey`: сочетание времени и относительного пути, исключающее смешивание одноимённых папок в разных ветвях.

### Validation

- `folderName` строго соответствует шаблону и реальной календарной дате.
- `folderPath` использует `/`, не содержит пустых значимых сегментов.
- `files` содержит минимум один JSON.

## PollingResult Source Extension

- `filename`: базовое имя исходного JSON.
- `sourceRelativePath`: полный относительный путь файла внутри выбранного дерева.
- `rawText` и `rawSha256`: неизменённое содержимое и контрольная сумма.
- Связь many-to-one с `PollingRun` через `runId`.

## ImportIssue

- `name`: имя или относительный путь файла.
- `stage`: `path`, `read` или `parse`.
- `message`: безопасное пользовательское объяснение без содержимого JSON.
- Ошибка не удаляет успешно созданные `PollingRun` и `PollingResult`.

## State Transitions

1. `selected` → пути разделены на JSON и игнорируемые файлы.
2. `grouped` → JSON распределены по валидным `PollingRunBatch`; неподходящие пути отклонены.
3. `read` → содержимое каждого доступного JSON прочитано локально.
4. `ingested` → группы по порядку добавлены в сеансовое состояние.
5. `reported` → UI показывает общий и групповой итог.
