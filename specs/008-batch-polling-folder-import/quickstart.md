# Quickstart: Проверка пакетного импорта

## Подготовка набора

Создайте вне репозитория тестовую папку:

```text
polling-export/
├── 2026-06-01_09-41-28/
│   ├── 10.10.10.1.json
│   └── 10.10.10.2.json
├── 2026-06-02_10-15-00/
│   └── vendor/
│       └── 10.10.10.3.json
├── invalid-date/
│   └── 10.10.10.4.json
└── note.txt
```

Используйте только синтетические JSON без реальных IP, логинов и паролей.

## Автоматические проверки

```powershell
node --check app.js
node tests.js
node scripts/validate-reference.js
```

Ожидается: синтаксис корректен, все тесты проходят, справочник синхронизирован.

## Ручная проверка

1. Откройте `index.html` двойным щелчком.
2. Перейдите в модуль «Загрузка».
3. В блоке результатов опросов выберите `polling-export` целиком.
4. Запустите импорт.
5. Убедитесь, что созданы два запуска, JSON во вложенной папке `vendor` отнесён ко второму запуску, `invalid-date` показан как ошибка, `note.txt` проигнорирован.
6. Перезагрузите страницу и убедитесь, что импортированные данные исчезли из памяти сеанса.

## Ожидаемое правило даты

`2026-06-01_09-41-28` означает 1 июня 2026 года, 09:41:28. Для 1 июля используйте `2026-07-01_09-41-28`.
