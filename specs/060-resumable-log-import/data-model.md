# Data Model

- Ревизия: текущая опубликованная версия; старая база содержит монолит, новая — упорядоченные ссылки на проверенные порции. Незавершённый перенос не меняет ревизию. Неизменные порции переиспользуются.
- Порция: контрольная сумма, порядковый индекс, служебные данные либо записи одного раздела. Ограничение размера относится только к порции.
- Checkpoint: область SR+версия+режим, ключ SHA-256 от пути/размера/mtime/префикса/формата/device/model, проверенные структурированные маркеры/паузы и контрольная сумма. Существуют независимо от браузера и состава папки; при завершении удаляются только опубликованные checkpoints.
