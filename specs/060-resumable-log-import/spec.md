# Feature Specification: Возобновляемый импорт и растущая рабочая база

**Feature Branch**: `codex/secure-local-runtime` · **Created**: 2026-11-18

**Status**: Implemented; эксплуатационная проверка полного архива остаётся на рабочем ПК.

## User Scenarios & Testing

1. **P1 — Сохранение истории:** совокупность безопасных обработанных данных больше 128 МиБ сохраняется и восстанавливается. Неудачная запись не заменяет последнюю опубликованную версию. Прежняя база открывается без повторного импорта.
2. **P1 — Продолжение:** после закрытия вкладки, остановки или сбоя администратор снова выбирает тот же набор файлов. Успешно сохранённые промежуточные результаты используются без повторного чтения содержимого; незаконченный или изменившийся файл не считается готовым. Проверка: принудительно прервать обработку посередине, возобновить и сравнить аналитику с чистым непрерывным импортом.
3. **P2 — Скорость:** при 102,64 ГиБ исходников ход импорта видим. Отображаются измеренная скорость чтения/анализа, количество файлов, повторно использованные результаты и отдельная стадия записи.

## Requirements

- Нет общего прикладного потолка 128 МиБ на историю. Размер порции может быть ограничен для защиты памяти, общий объём зависит от диска и ресурсов.
- Промежуточные результаты хранятся в явно выбранной рабочей базе, без оригиналов логов или секретов. Неполный импорт не подменяет готовую аналитику. Изменение SR или отпечатка источника запрещает неподтверждённое повторное использование.
- Правила событий и выводы о достоверности остаются прежними. Повторно использованные файлы не засчитываются как фактически прочитанные данные для скорости.
- Ручной запуск без базы остаётся доступен, но без восстановления после закрытия вкладки.

## Success Criteria

- Синтетическое сохранение и восстановление больше 128 МиБ; прерванное сохранение оставляет прежнюю ревизию.
- На повторе чтение тела каждого сохранённого неизменившегося файла равно нулю. Итоги и порядок доказательств совпадают с непрерывным импортом.
- Скорость обновляется во время чтения, не растёт из-за пропущенных файлов; при завершении пользователь различает сводку и запись.

## Clarifications

- Масштаб подтверждён: 102,64 ГиБ текущих исходников, данные будут расти. После перезапуска папку выбирает администратор; непроверенные новые файлы не считаются уже обработанными. Дополнительных решений пользователя для этой реализации не требуется.
