# Workspace V2

Существующие session, admin, Host, Origin и CSRF применяются ко всем операциям. Перенос начинает staging для ожидаемой ревизии, принимает порции или ссылки на прежние порции, затем атомарно публикует последовательность; восстанавливает по номеру ревизии и порции. Legacy снимки читаются без изменения.

Контрольные точки логов публикуются отдельно по области SR/версии/режима и SHA-256 ключу источника, на повторе возвращаются сохранённые производные данные. Смена рабочей базы блокирует операции старой вкладки. Неуспешное чтение не создаёт готовую контрольную точку.
