# Обновление и проверка

1. Дождаться завершения текущих опросов и сохранения базы. Старый bulk HTTP/Telnet
   план не продолжать: после обновления он будет отклонён.
2. Закрыть прежний Python runtime, обновить весь проект и снова запустить
   `START_MVP_SPHERE_SR.py`. Одного F5 недостаточно: изменены также Python guards,
   checkpoint validation и SQL-проекция качества источника.
3. Открыть прежнюю рабочую базу. Не удалять её и не редактировать исходные XML.
4. Выбрать ту же полную папку логов и продолжить импорт с прежним режимом
   перепроверки. Готовые неизменённые scans текущих правил будут использованы
   из контрольных точек; повторное чтение их тела не требуется. Ранее отклонённый
   распознаваемый фрагмент будет прочитан и опубликован с предупреждением.
5. Проверить успешную публикацию с замечаниями и события. Если возникнет настоящая
   ошибка чтения, прежняя аналитика останется активной; UI покажет имя и причину.
6. В разделе 4 загрузить XLSX: действия и сборы не выбраны. Указать только нужные
   Answer mode группы, проверить preview. HTTP/Telnet останутся «Не менять».
   Отдельные портовые действия TE20 выбираются только явно и сохраняют прежние
   модельные/одноточечные ограничения. Автоматического возврата портов нет.
