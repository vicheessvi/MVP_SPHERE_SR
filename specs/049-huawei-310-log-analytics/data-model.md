# Данные

- `LogMarker`: вид (`web_reboot_command`, `web_shutdown_command`, `system_boot`), локальное время, номер строки. Сырого сообщения нет.
- `LogEvent`: подтверждённая перезагрузка, штатное выключение либо запуск с неустановленной причиной; способ `web`/`remote_control` при подтверждённом действии, deviceId/IP текущей SR, локальное время, версия правила, метаданные источника.
- `Coverage`: проверенные/исключённые файлы, ожидание Box, ошибки разбора и число событий.
- `BoxLogEvent`: событие точной Box 310/610 с `validationStatus=confirmed_user_validation` и собственной модельной версией правила; входит в общий индекс Huawei 310 после пользовательского подтверждения, но не меняет исторические предварительные результаты.

Файлы импортируются только в памяти вкладки. Смена SR делает индекс устаревшим до повторного импорта.
