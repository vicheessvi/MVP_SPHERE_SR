# Проверка

1. В модуле загрузки импортировать общую локальную папку логов с файлом Bar 310 `<IP>.xml` и актуальную SR с одним устройством по этому IP.
2. В модуле «Анализ перезагрузок устройств» проверить отдельные области Bar 310: подтверждённые перезагрузки, штатные выключения и неизвестные запуски.
3. Импортировать тот же файл повторно: счётчики не должны удвоиться.
4. Проверить синтетические варианты пульта: два близких нажатия и boot дают одну перезагрузку; одно нажатие с командой выключения — отдельное выключение; одно нажатие без команды, два далёких нажатия и внутренние restart не подтверждают перезагрузку.
5. Для Box 310/610 проверить общие разделы Huawei 310: события по точной модели/IP, отсутствие дублей, участие в кольцевой диаграмме и тепловой карте. Администратор подтвердил результаты обеих моделей 2026-11-13.
