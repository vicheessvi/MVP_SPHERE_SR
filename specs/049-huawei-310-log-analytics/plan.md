# План реализации: события из журналов Huawei 310

**Ветка**: `codex/secure-local-runtime`
**Спецификация**: [spec.md](spec.md)
**Дата**: 2026-11-12

## Подход

Отдельный от TE потоковый браузерный парсер семейства Huawei 310 читает только локально импортированный XML `LogModule`. По модельным правилам создаёт минимальные события. Существующий индекс SR обеспечивает точное сопоставление IP, дедупликацию и фильтры; старый TE/Extron анализ не меняется. Предварительный просмотр Box был изолирован до отдельного подтверждения администратором; теперь Box 310/610 входят в основной индекс с собственными версиями правил.

## Технический контекст

- HTML/Vanilla JavaScript, browser File API; runtime Python не получает импортированные логи.
- Файлы: `runtime/huawei-310-log-events.js`, `app.js`, `index.html`, `tests.js`, `product-catalog.js`.
- Содержимое читается последовательно, не попадает в state и не передаётся в сеть.
- Проверки: `node tests.js`, `node --check`, `node scripts/validate-reference.js`.

## Конституционные ограничения

- Оригинальный XML не изменять; производные события содержат только тип, локальное время и источник.
- Exact модель/IP и единственность строки SR обязательны; неизвестное не превращать в событие.
- Версия правила стабильна, повторный импорт детерминирован.
- Никаких новых сетевых endpoint, зависимостей и хранения секретов.
