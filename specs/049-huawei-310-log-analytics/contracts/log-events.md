# Контракт анализа Bar 310

Только exact Bar 310 и однозначный IP текущей SR. Вход — локальный XML с корнем `LogModule`; парсер читает ограниченные строки без выполнения XML. Проверенная успешная web-команда `reboot terminal` плюс следующий `System boot` в пределах трёх минут дают одну `confirmed_reboot` со способом `web`. Для способа `remote_control` требуются два отдельных `Remote control power button` с интервалом не более 30 секунд и затем `System boot` в пределах трёх минут без команды выключения между ними. Web-команда `shut down terminal` даёт отдельный `power_off` со способом `web`; команда `user shut down terminal` после кнопки пульта в пределах 10 секунд даёт `power_off` со способом `remote_control`. Ни то ни другое не доказывает аварийную потерю питания. Прочие System boot — `unknown_start`. Слова `restart`/`reboot` из внутренних подсистем сами по себе игнорируются.

Новый System boot в пределах десяти минут после подтверждённой команды выключения показывается отдельно как `start_after_shutdown`, а не как новая перезагрузка или «причина не установлена». Box 310/610 не получают событий по этому правилу. Их файлы доступны в метаданных импорта со статусом ожидания проверки.
